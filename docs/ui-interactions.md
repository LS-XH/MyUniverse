# 界面与交互约定

更新日期：2026-10-09。本文整理历次界面修改；设计理由与实现参数见 [设计原则](design-principles.md)；需求总表见 [Planning](../Planning.md)，源码格式与同步见 [Markdown 双向编辑](markdown-sync.md)。

## 导航与项目树

最左侧 `rail` 在创作、插件、设置之间切换，背景和左侧白色指示条随选择移动。对应侧边栏分别为 `sidebar creation-sidebar`、`sidebar plugin-sidebar`、`sidebar settings-sidebar`。

创作侧边栏顶层为“创建世界”和“我的项目”。创建入口沿用树行样式，字号、粗细和高度略大，+ 与父集合文件夹图标对齐。全部世界在“我的项目”下展开；世界子项适当缩进，层级引导线独立于条目缩进绘制，计入树行边距后与父对象图标中心对齐并只覆盖实际子项；调整引导线不移动条目。创建世界、我的项目及世界树位于同一个 `projects-scroll` 滚动区。侧栏可展开项最右侧显示 ChevronDown / ChevronRight，以父对象图标对齐引导线；单击名称仅打开页面，右侧箭头或双击名称展开/收起。删除世界下拉选择器、搜索框、分区标签、分隔线与侧边栏底部提示，保持连续树结构。文件和视图条目均可以收起其属性/界面配置。

选择世界打开该项目的顶层集合对象列表，右上角红色按钮删除项目，操作有确认提示。集合页可创建子集合、Class 文件及已有类型的界面；内置类保留删除保护。顶栏显示导航路径及侧栏/Markdown 分栏开关，移除原右侧工作台/头像区。

## 文件操作与属性配置

字段标签使用主要文字颜色。类名旁边的大号加粗 + 创建实例；加号无独立实心圆底，圆角范围提供悬停与按压反馈。实例名称直接编辑，悬停/聚焦时在名称左侧显示铅笔图标。删除原“每个实例将保存为 Markdown 二级标题……”说明。

实例卡片和集合卡片具有悬停、按压动画，实例还提供聚焦反馈。标题操作区按钮也有悬停和按压反馈。系统要求减少动态效果时关闭相关过渡。

### 拖动排序

属性条左侧 `schema-grip` 和实例卡片左侧手柄使用 `SortHandle`：

- 按住手柄上下拖动，超过少量移动距离后进入排序。
- 半透明副本跟随光标移动，原项从可见列表中提起；目标位置保留与原项同宽同高的占位，其他项平滑移动并让出空间。
- 展开的实例或 Object 属性按完整高度参与占位，包含其字段/子属性。接近操作区上下边缘时自动滚动。
- 拖动中不提交数据，只调整视觉位置；松开后保存排序，取消时恢复原始位置。
- 松开提交，Esc、指针取消或窗口失焦取消。
- 聚焦手柄后，方向键上/下移动一项。
- 属性仅在同一父结构中排序，不跨父对象；实例仅在所属类中排序。
- 属性顺序写入 `.schema.json` 并同步实例字段；实例顺序体现在 Markdown 二级标题顺序中。

使用指针事件与捕获，不依赖 HTML `draggable`/DataTransfer，避免桌面 WebView 原生文件拖放产生禁止光标。

### Markdown 面板

文件操作页右上角“导入 MD”打开文件选择与识别确认；主顶栏固定的 PanelRight 按钮切换右侧独立源码列，开启时收窄留白并分配双栏空间。关闭按钮或 Esc 关闭；点击空白或编辑左侧字段时保持打开。

左侧选中或修改实例名、对象键、值时，定位对应源码标题或值内容，自动滚动到可见位置，并使用透明浅绿色高亮。右侧支持直接编辑，合法内容解析回对象再自动保存；格式有误时保留草稿及最后有效对象，显示错误。离开右侧编辑框也触发解析。有效源码在重新选中左侧字段时规范化。高亮颜色由主题 `markdownHighlight` 控制。源码使用可编辑区域显示原始 #，按标题级别放大加粗（一级 23px、二级 20px，逐级递减）；代码围栏及转义标题保持正文样式，行定位按实际排版计算。

## 关系网

关系网使用整个画布操作区；文字不可选中，避免 Shift 操作产生文本高亮。

| 操作 | 行为 |
| --- | --- |
| 左键拖动空白区域（移动超过 5px） | 平移画布，保留已选人物或连线 |
| 点击空白区域（未超过拖动阈值） | 取消选择 |
| 点击人物 | 选择人物并显示详情 |
| Shift 拖动空白区域 | 框选人物 |
| Ctrl/Shift 点击人物 | 增减多选；macOS Meta 同样可用 |
| 松开修饰键后拖动选中人物 | 全部选中人物一起移动，保留相对位置 |
| 滚轮 | 以当前光标为中心缩放，范围 8%–300% |
| 底部缩放按钮 | 以画布中心缩放，使用同一倍率范围 |
| 拖动人物到可见画布边缘 | 视角自动平移，多选集合一起移动；光标保持在边缘时持续平移 |
| 连线按钮 | 开关连线模式，再次点击退出 |
| 先选人物再开启连线 | 使用该人物作为起点，点击第二个人物完成 |
| 不选人物开启连线 | 依次点击两个人物完成 |
| 已选连线起点后移动光标 | 显示到光标的半透明预览线 |
| 点击实际连线 | 查看、编辑关系及删除连线 |
| PanelRightClose/PanelRightOpen | 关闭、打开浮动人物详情 |

默认即为选择状态，不增加单独选择按钮。连线保存于起点人物的“人物关系”中；箭头从该主语人物指向目标人物，停在目标卡片边缘，不自动生成反向关系。卡片显示姓名及“所属势力 · 势力地位”，未配置时提示未设置势力。

顶部工具条收窄，与详情标题高度协调。卡片为 210×88px，姓氏图标 52×56px、字 25px，姓名 18px，势力副标题 14px，内边距 8px，以改善可读性。SVG 边界根据全部人物与连线预览光标计算，支持负坐标及超出原固定矩形范围的节点。

### 关系和势力样式

添加映射时选择当前世界实际存在、尚未映射的关系或势力实例；既有映射可下拉切换实例。关系配置包括填充/边框颜色、发光范围、线型、文字大小、线宽（0.5–20px，默认 2.5px）及外围边框宽度（0–10px，默认 1px）。背景域按所属势力分组，可开关，支持颜色及纯色、点阵、斜线、虚线、网格图案。

线宽、颜色、文字与方向箭头已应用到画布。长划线、短划线及划线点线使用各自参数，配置发光也应用到画布。双实线仍待实现。

## 聊天与地图

聊天框的树下直接放置配置、新建聊天和各条对话记录，支持切换和删除会话，不另设会话导航页。聊天区域覆盖主操作区，不使用 `preview-shell` 限定容器；空会话的输入框居中，有会话时输入框置底。发送用户消息时自动创建/更新会话并保存到当前世界。

输入框左下角为模型菜单，列出启用的模型并记住当前世界选择；尚未配置时可以进入设置。当前不发起服务请求、不生成助手回复。

地图示意 UI 覆盖整个操作区，移除限制范围的 `map-grid`。地图文件和图例配置可以保存，真实加载、缩放、拖动与地点交互仍待接入。

## 设置、颜色与滚动条

主题提供星雾蓝紫、经典暗黑和晨光浅色。预设只读，可复制当前配色新建主题并编辑名称和颜色，也可删除自建主题。颜色使用共享语义项，覆盖背景、文字、按钮、树、节点、聊天、地图和 Markdown 高亮。

自定义颜色选择器为点击色块附近的浮动菜单，提供 ARGB 透明度、通道和十六进制输入，不调用系统颜色对话框。提供 8 列 × 8 行预设网格：绿、蓝、紫、红、橙、黄、青、灰分别占一列，同列由深到浅；同一行展示不同颜色。预设选择保留当前 A 通道。色块在圆角按钮内保留留白。八位颜色按 `#AARRGGBB` 解释，再转换为 CSS RGBA。

“模型”是可折叠树，下方显示全部连接配置。主界面显示并编辑连接，右上角添加模型；支持名称、模型标识、接口地址、隐藏输入的 API Key、启用/停用及删除。停用模型不进入聊天菜单，删除会清理各世界选择。真实模型调用属于后续工作。

滚动条采用 CSS 定制的原生滚动条：窄圆角滑块、透明轨道及主题色反馈，不是独立 JavaScript 滚动组件。

关系格式在宽操作区中将填充颜色、边框颜色、发光范围、线型、线宽、边框宽度及文字大小排在同一行；窄窗口自动换行。颜色预设为等宽等高的方形，每个色系提供八级深浅。

## Function 绑定

所有 Value 类型可绑定多个 Function。原值保留，函数返回值以更深一级的 `[函数名](../../functions/<函数ID>.js、py或flow)` 标题保存；解析时恢复为独立函数结果，不混入普通子属性或原值。对象引用与关系格式实例菜单共享原值/返回值选择。脚本管理、示例、错误处理、编辑行为及运行环境要求见 [Function](functions.md)。

## 插件文件夹与树视图

插件侧边栏的技能、函数、工具共用 PluginTree，可展开/收起分类和文件夹；层级竖线只覆盖实际子项，并与父图标中心对齐。行内 FolderPlus 在悬停/聚焦时显示，主操作区提供新建文件夹。三个分类均支持嵌套文件夹、重命名与删除；删除文件夹会把文件和子文件夹移到上一级。函数编辑页可选择所属文件夹，新增/导入归入当前文件夹。技能与工具的文件编辑仍待实现。

## Flow 编辑

右侧操作/文件操作树可点击或拖入卡片。输出端口到输入端口点击连线，双击输入断开；拖标题移动卡片，拖空白平移，滚轮围绕光标缩放。可适配全部节点、展开画布、删除节点或连线。代码块可增加、删除、重命名输入，并展开编辑；对象助手与 JS/Python 编辑器共用，按光标位置插入稳定 ID 调用。文件卡片逐级选择 Class、实例与成员。

## 列表滚动与批量人物编辑

entity-list 独立纵向滚动，page-heading 和操作按钮固定在列表上方；其他 page-scroll 的标题吸顶。排序自动滚动使用当前实例列表容器。属性配置、函数与关系格式使用居中内容列，在合理宽度内由内容撑开，不强制所有控件拉满窗口；关系格式实例与全部参数优先同排，窄窗口按各页面规则换行或滚动。

关系网连线模式允许空白处拖动平移，ESC 退出并取消起点。拖人物时仍可滚轮缩放。边缘平移依据整组卡片的屏幕边界，最多向内 160px 开始触发，距离越近越快，上限 1400px/秒。拖动视角保留选择；Shift+Ctrl 框选追加选择。

多选详情显示所有选中人物共有属性，相同值直接展示，不同值使用明确提示。修改单项或清空将应用到所选人物，保留各自字段 ID、其他内容及未选中人物。仅匹配唯一存在的字段；重复成员不明确时不提供批量编辑。

### 关系配置居中布局修正（2026-10-09）

关系网配置标题与内容分为独立区域，标题固定、内容单独滚动，避免吸顶后露出顶部内容。标题与面板共享居中宽度（上限 1280px），为滚动条对称预留空间；宽窗口保留两侧留白，控件根据内容扩展，数值框不随窗口无限拉伸。统一控件高度、标签行高、列间距及各格式行上下内边距。

### 文件及属性页面居中与 Markdown 空间分配

文件操作的标题与实例列表共享居中内容列（上限 1180px），属性配置的标题、结构面板与提示共享居中内容列（上限 1280px）。宽窗口保留两侧留白，内容可在列内扩展。开启 Markdown 时收窄操作区左右留白，并为右侧独立 Markdown 列分配空间；关闭后平滑恢复居中布局，预览不再遮住实例卡片。

关系线发光由填充色产生，填充线与箭头共用发光层；边框独立渲染，不使用边框色产生光晕。悬停保留原有线型、线宽和颜色，并增强填充光晕。

关系线悬停光晕采用 240ms 渐入渐出，亮度增强同步过渡；系统偏好减少动态效果时关闭动画。

属性配置标题与内容分为独立固定区和滚动区，避免滚过的属性出现在标题顶部。文件实例列表的裁切边界紧接标题下方分隔线，列表内部保留初始间距，取消标题与滚动容器之间的外部空隙。

### 页面会话、双栏与侧栏操作

关系网“在人物列表中打开”传递人物 ID，列表展开并滚动到目标卡片，高亮约 4 秒。Markdown 预览改为独立双栏，保留编辑、行定位和关闭按钮，不再点击空白关闭。

每个世界、节点与配置页使用独立页面会话，切换后恢复滚动位置；人物列表恢复展开项和双栏状态，关系网恢复视角、倍率、选择及详情栏，Flow 恢复画布位置，聊天保留输入草稿。状态仅保存在当前运行中，不写入 Markdown 或工作区 JSON，重启会重置。

左键侧栏对象仅切换页面；右键对象进入对应页面并在鼠标位置显示页面操作菜单。应用禁用 WebView 原生右键菜单。菜单调用当前页面实际工具栏按钮，复用禁用状态、开关、文件导入和删除确认。点击外部或 ESC 关闭菜单；无对应工具栏操作的页面显示暂无快捷操作。

### 函数页面与执行异常

函数页面使用独立固定标题和内容滚动区域，标题与内容共享居中宽度，统一配置、代码、测试区域间距。执行失败展示可复制的完整异常：JS 堆栈、Python Traceback、进程退出码及失败日志、运行环境启动错误。异常面板出现时自动滚动到该面板。支持 transform(input) 中直接访问 world，不强制增加第二个参数。

### 对象引用菜单不受卡片裁切
对象选择和 # 引用建议菜单渲染到页面浮层，脱离实例卡片与滚动容器的裁切范围。菜单跟随输入位置，靠近窗口底部时向上展开，限制在窗口内并支持菜单内部滚动；点击外部或 Escape 关闭。

### Function 类型接口 v2
新建 JS/Python/Flow 函数使用 transform(self, input)：self 为调用实例，input 为绑定 Value 的类型对象，提供 value、to_value、成员读取和 Class 实例读取。函数设置可声明返回类型，Object / Class 可选择已有类作为规范；返回结构使用 values 构造器，校验类型、成员、日期、安全整数及引用。测试选择实例与属性并允许编辑类型 JSON；调用助手与补全支持新接口。旧脚本保留字符串兼容模式。结构化结果展示为 Markdown 并保存可逆类型元数据，原值不变。完整接口见 docs/functions.md。

### 侧边栏收起与集合操作
创作、插件、设置侧边栏右上角提供 PanelLeft 按钮。收起时侧边栏宽度归零、内容向左滑动淡出，按钮同步移动到主界面左上角；展开时反向恢复，保留页面及侧栏状态，支持减少动画偏好。自建集合的页面工具栏和右键对象菜单提供红色删除按钮，确认后仅移除集合，内部对象移至上级，默认集合不可删除。对象菜单各项复用页面按钮的 SVG 图标，左键切换页面、右键显示操作菜单的规则保持不变。

### Markdown 分栏顶部开关
文件操作页面的 Markdown 开关移至主界面顶栏，使用 PanelRight 图标，移除实例页面标题工具栏及 Markdown 子面板内的重复开关。按钮始终固定在主界面右上角，不随分栏移动。预览标题区延伸至主界面顶栏顶部，包含文件名、保存状态与分页按钮，与下方源码列对齐；标题区和分栏宽度、透明度同步渐变。仍保留分页、页面状态记忆、实时编辑与定位高亮，并可从右键对象菜单调用顶栏开关。

### 树视图选择与展开分离
侧栏可展开项的最右侧放置独立 ChevronDown / ChevronRight 按钮：展开时向下、收起时向右。箭头按钮为 22px 方形，在树行内垂直居中，上下保留空隙。单击名称仅打开操作页面，不修改子树状态；点击右侧箭头或双击名称才展开/收起。适用于世界项目、集合、文件/视图配置分支、插件集合与文件夹、模型和主题集合。无子对象的叶子项不显示无效展开按钮。我的项目单击打开全项目列表。右键打开对应页面操作菜单，不再顺带展开/收起子树。

### Function 返回值只读成员视图
函数成功结果根据 typedValue 渲染，与普通成员共享 field、object-body、text-reference、reference-trigger 等界面样式。Object 递归展示子成员；Text、Integer、Decimal、Data 使用只读输入框，Content 使用只读多行框；Class 值及 Class 引用键使用禁用的对象选择按钮，显示类名和实例名，不打开菜单。返回类规范存在时复用其成员键类型，动态文本键也使用只读输入框。Null 显示无内容，空 Object 显示无子成员。结果不提供增删或编辑操作，文本可复制；旧字符串结果显示在只读多行框。错误和等待状态保留，Markdown 序列化与结构元数据不变。

### 属性控件自适应宽度
对象引用控件使用紧凑的内容宽度，函数返回值来源选择（使用原值等）与当前 Value 同行，空间不足时才换行。Text 短文本框默认约 240px，随输入内容增长扩展至可用空间上限；Content 多行文本保持宽幅编辑。只读函数返回值复用相同尺寸规则。

### 属性成员卡片交互
文件操作界面的每个键值对使用独立圆角卡片，包含键、值及绑定函数结果。光标悬停时向屏幕外轻微放大（约 0.8%），不向上平移，按卡片内相对坐标以最大约 1.6 度向光标倾斜；离开后渐变恢复，背景、边框、阴影同步过渡。嵌套属性仅突出当前卡片，不叠加父级旋转。保留输入、下拉菜单及 Markdown 行定位，减少动画偏好下停用位移与旋转。

属性配置界面复用同一成员卡片及光标倾斜交互。文件操作的成员层级线移除，嵌套卡片左侧缩进缩小，以卡片边界表达归属。属性配置、文件操作的添加属性及添加子项按钮使用无边框圆角背景，悬停与点击时平滑高亮，键盘聚焦可见。

### 设计规则与实现边界

成员卡片、输入框、导航树及双栏的完整规则见 [设计原则第 2–8 节](design-principles.md)。FieldCard 只负责展示反馈，不提交对象更新；SchemaRow 保留完整父级排序单位。只读函数成员复用输入样式，递归子项本身不自动新增可编辑操作。卡片动画目前已完成编译验证，实际浏览器和桌面视觉效果需以运行版本验收为准。
