## 人物关系网

### 元素与关系上下文

| 绑定槽 | 职责 |
| --- | --- |
| title、avatar、subtitle | 节点标题、头像/字符、副标题 |
| domain、domainLabel | 分组实例引用、分组显示名 |
| edges | 可重复关系成员集合 |
| target | 相对单条关系成员的目标 Class Key/Value |
| edgeLabel | 相对关系成员的关系类型；每个重复值生成一条独立连线 |

人物关系网由 personGraphView 读取人物类当前 Schema：人物关系 Object → Class-人物重复项 → 关系 Object → 可重复 Class-关系键 / Null 值；目标为人物重复项的 Class 键。关系标签和取色身份读取关系列表子项的 Class 键，不读取其 Null 正文；旧直接 Class-关系 Value 仍兼容，按 Schema 的键/值类型区分，不靠显示文字猜身份。姓名与首字头像来自人物实例名称，势力名称和地位来自人物势力成员。路径使用现有 Schema ID，不改写用户 Schema。旧保存的自定义 graph 父类/绑定不再参与显示；布局、样式、开关和文件身份保留，保存时规范为人物配置。地图仍可配置当前/固定绑定。

edgeLabel 使用关系列表的子项路径及 part=key，读取同一路径下所有匹配成员。每个重复关系值生成一条独立有向线，即使引用同一关系类型也不合并；每条线仅显示该值的名称，并采用其对应关系类型的格式。身份由外层人物关系成员 ID 与关系值 ID 共同确定，目标仍取外层人物引用。旧直接 Class-关系 Value 同样逐值显示，旧 labelSource 不覆盖关系名称。

“显示函数生成关系”默认开启，独立于关系文字开关。关闭后，投影跳过带 functionOrigin 的关系成员及其祖先生成的子树；手动关系内仅过滤函数生成的标签值，保留手动标签。过滤后无关系值的组不绘制。此开关不删除字段、不改变函数绑定，也不隐藏人物卡片；详情定位选中连线的原始关系值，保留其他隐藏成员。函数生成值及生成祖先内的值不可手动编辑或删除。

可新增关系要求人物关系列表具有可重复 Class-人物键结构。写入通过已有 Schema 创建缺失路径和子成员，保留字段身份；不符合人物结构时不开放新增连线，不退回自定义绑定或从显示文字猜目标。

新建人物连线默认使用“妈妈”关系，直接写入有效 Class 引用，连完即可投影显示；已有“妈妈”实例时复用，缺失时按关系类配置创建一个普通实例。关系实例与连线作为同一次编辑提交，可一起撤销。关系类型网仍以原关系推理的起点/键规则创建，不改为妈妈；用户主动设置的关系筛选及格式可见性继续生效。

### 关系类型筛选

人物关系网与关系类型网的工具栏，在函数生成关系开关左侧提供关系类型复选下拉菜单。第一项为“全选”，其后列出当前类的每个关系类型；默认全选，仅绘制勾选类型的连线，多种类型可同时显示，全部取消时没有关系线。部分勾选时“全选”显示半选，点击可恢复全选；全选后再取消则清空全部。勾选后菜单保持展开，点击外部或 Esc 关闭，Esc 将焦点返回触发按钮。选项多时滚动，“全选”保持在顶部。

每个关系类型复用标准实例下拉条目 ReferenceOption：复选框、所属类徽标、实例名称，背景取该实例所属标签的颜色并保留 ARGB 透明度；无标签时回退主题。与 ReferencePicker 共用标签解析、徽标和条目皮肤，不另写关系筛选专用实例皮肤。

完整图保留所有实例卡片，个人聚焦视图按筛选后的连线展示邻居。筛选与函数生成关系开关、配置中的格式可见性叠加生效，同类型多条连线继续分别显示。筛选仅记录在当前页面会话，不修改世界对象或 Markdown；旧会话的单选状态按一个勾选类型兼容。关系类型改名仍按 ID 保持选择，删除的类型从已选集合移除；全选状态自动包含新增类型，显式部分选择不自动包含新增类型。

### 视角中心新增实例

关系网的添加按钮在当前可见画布中心放置新卡片，以卡片中心对齐视口中心。位置按当前平移与缩放反算世界坐标，右侧详情展开时扣除遮挡区域；不修改当前视角。个人聚焦中新增卡片也立即显示，完整视图位置随创建一起保存。人物关系网和关系类型网共用该行为，创建可撤销/重做。

### 页面操作历史

关系网的历史按世界与视图身份隔离，切换文档、配置或其他视图后返回，撤销与重做栈继续保留。同一世界不同视图各自记录操作；撤销使用反向差异合并，保留其他页面的无关修改。一次拖动、排版或连线仍作为一次操作，撤销后产生新的编辑只清除该页重做栈。记录属于当前应用会话，不写入 JSON 或 MD。关系网保留最近 50 步，对象列表最近 80 步，工作流/Flow 画布最近 100 步。

### 源数据编辑

连线支持 Ctrl / Command（也兼容 Shift）点击多选，再次点击已选连线取消该项。选中卡片与选中连线互斥。详情栏自动随有效选择展开，点击画布空白或取消最后一项选择后收起；手动收起后可通过详情按钮或再次点击对象展开。多选连线显示“已选择 N 个关系”，共同属性修改应用到所选可编辑关系，保留各条线的身份和其他属性；不同原值显示混合提示。函数生成的关系单独提示数量并保持只读。一次批量修改或删除只记一次撤销记录。

节点详情直接编辑人物实例。新增节点创建人物实例；新连线添加源实例的人物关系成员及一个默认“妈妈”的可编辑关系值，箭头目标由引用决定，不自动反向写。点击连线仅编辑该关系值，删除时保留同组其他关系值与人物关系小故事；删除该人物项最后一个关系值时，同时删除源人物“人物关系”中对应的目标人物项及其子属性。判断依据为完整数据，包括被筛选隐藏的关系和函数生成的关系；不删除人物实例或对方的反向关系。多选仅批量修改唯一存在的共同成员，保留每个对象自己的 ID 与其他值。

源成员修改走统一世界与 Markdown 保存，视图不单独维护人物/关系数据。人物内容或 Schema 改变后的显示实时更新，不因缓存保留旧值。

### 独立布局与样式

工具栏“自动排版”采用分势力的多级中心聚簇网络。连接最多的人物保留在主中心；每个势力选自己的枢纽，簇内按局部连接亲和构建分支，再用真实关系的吸引与卡片排斥调整位置，使外围枢纽拥有自己的子分支。未归属势力的人物按相互连通的分量聚簇；同势力中没有已知路径的人物仍保留在该势力内部，布局用的临时分支不写成关系。

势力完整背景矩形参与打包，矩形之间保留至少 180 个世界坐标单位的间隔，簇内卡片分别保留间距，不再按全网同心圆均匀分布。跨簇位置搜索、整簇镜像以及簇内同分支末端次序优化，显式计入连线交叉、穿过其他卡片和穿过无关势力背景的代价。复杂关系无法保证零交叉；很密的图采用确定性边采样控制优化开销，不再因超过 180 个节点而完全停用交叉评分。

布局基于当前函数生成关系显示开关下的完整关系网，不受关系类型筛选影响；在个人聚焦状态点击会返回完整关系网并排版，随后适应画布。调整作为一次编辑进入撤销历史。仅点击按钮时更改位置，不自动重排已有存档。

graph-top 的操作入口使用 [标准顶栏图标按钮](../ui/styles.md#组织与使用)组合 ui-surface、ui-button、ui-button--icon、ui-button--topbar-icon，尺寸和皮肤由共享变体提供，不由 graph-tools 覆盖。图标为 20px：关系类型筛选使用 ListFilter，函数关系开关使用 SquareFunction，关系文字开关使用 CaseSensitive，自动排版使用 LayoutTemplate，连线使用 Waypoints，添加实例使用 Plus；撤销、重做、删除、返回和详情入口也使用图标。每个按钮保留 title 提示与无障碍名称，函数关系、关系文字和连线用按下状态及高亮表示当前开关，筛选启用或菜单展开时也高亮。

Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做（也支持 Command）；Delete 删除所选人物或可编辑连线，R 切换连线模式。输入框和弹窗内不触发画布快捷键。拖动释放、自动排版、新增/删除与详情修改进入当前视图会话的编辑历史；一次拖动记为一步，历史最多 50 步，切换视图保留各自历史。撤销按本次修改合并，保留其他位置的独立编辑；个人聚焦位置是临时视图，不进入持久化历史。

人物关系网与关系类型网共用连线避让：同一对卡片的双向连线、同向多个独立关系成员分别使用不同曲线，标签随各自曲线定位；单条连线保持直线。人物单个关系成员下的多个重复值也分别绘制曲线，不改写源数据结构。自引用按环线绘制。

graph 保存 positions、lineStyles、domainStyles、showDomains、showLabels、showFunctionRelations。showFunctionRelations 缺省按 true 兼容旧项目，保存于各视图配置而非全局主题。布局以实例 ID 为键，关系/分组样式按实际类型实例映射。缺省位置仅为展示，拖动后保存视图覆盖。

线条支持 ARGB 填充/边框、发光、线型、线宽、边框宽及字号（旧 labelSource 仅兼容，当前 UI 不提供标签来源选择）；背景支持填充/边框、发光及纯色、点阵、斜线、虚线、网格。选择器为程序 ARGB，8×8 色板保留透明度。

长/短划线与划线点线使用不同参数，线、外框和箭头有独立正确几何范围。双实线为配置选项，但当前渲染仍需完善，不能视为所有线型完成。交互尺寸与选择见 [页面 UI](../ui/pages.md#人物关系网)。

### 人物个人关系网与格式可见性

双击人物卡片进入个人关系网，标题右侧的滑动条选择 1～5 级，默认 1 级。中心人物居中，以入向和出向关系的最短跳数分层，各层人物从内到外按环排列，并显示层级辅助环。保留可见人物之间的交叉关系；循环、自引用和多条平行关系不会重复创建卡片。层级展开受当前关系类型、函数关系和格式可见性筛选共同约束。没有关系时仅显示中心人物。返回按钮或 Esc 恢复完整人物关系网的视角、缩放、选择及详情栏状态；个人布局属于页面会话状态，拖动和缩放不会覆盖完整人物关系网的持久化位置。

关系格式的 `lineStyles[关系实例ID].visible` 控制该关系类型的显示，缺省为 true。重复关系逐值过滤，剩余每个值分别显示一条线及其对应文字与格式；关闭某类型只隐藏该类型的线。此过滤与函数生成关系开关共同生效，不修改人物原始成员。关系格式与背景块格式分组首次进入默认收起，可通过标题展开；添加映射会自动展开对应分组。

## 关系类型网

固定读取内置 `relations` 类（树中的“关系类型”类别）。每个实例生成一张卡片：实例名称为标题，“关系描述”为副标题，放在人物卡片原势力名与地位的位置，不显示势力背景。

以当前实例为起点，遍历“关系推理”Object 下的每个重复成员：Class Key 引用决定连线文字和样式，Class Value 引用决定终点。两者均需引用当前世界的关系类型实例；无效或跨类引用不绘制。每个成员是一条独立有向线，多条相同端点的推理采用弧线分开，自引用显示环线。函数生成关系开关和关系格式可见性同样生效。

复用人物关系网的平移、缩放、多选、卡片拖动、详情编辑和双击聚焦。新增卡片创建关系类型实例；新增连线写入起点的推理成员，Key 默认引用起点，Value 引用终点，可在连线详情修改。源内容、布局和格式自动进入 JSON 存档，按需导出对应文件。

### 从人物关系网配置导入

打开“关系类型网配置”，在“从人物关系网配置导入”中选择同一世界的人物关系网，点击“导入配置”。复制其关系连线格式及文字、函数生成关系显示开关，替换当前连线映射；过滤已不存在的关系实例，移除旧 labelSource。复制后配置彼此独立。

导入保留目标视图的名称、ID、文件名及卡片位置，不复制人物位置或势力背景。导入后点击保存当前文件或保存全部；尚无人物关系网时先创建来源界面。

新世界默认包含关系类型网，旧世界加载时补入一次。删除后不会在下一次加载重新创建；可通过新建界面的“关系类型网”类型重新添加。原默认“关系网”名称迁移为“人物关系网”，自定义名称及原配置文件身份保留。

## 地图

父类实例生成标记，title/description/x/y/image 由绑定得到。源坐标需为有限数值文本；没有可用坐标时使用默认布局。view.map.positions 优先覆盖源坐标，拖动只修改该视图布局，不写源字段。

背景取 image 绑定（当前模式以首个父实例解析，固定模式用固定对象），缺省 view.map.image；legend 为视图配置。支持平移、光标缩放、标记选择/拖动、适应视图和双击打开父类实例。地图是图片坐标投影，尚无 GIS 经度纬度、地图服务或坐标反写契约。

### 关系网文档顶栏

关系网显示与对象页一致的七项文件操作，目标是视图对应源类的 MD，而非 view.json。DocumentFileActions 共用文件选择、校验、填入/替换确认和逐实例提交；保存、刷新及重新计算复用当前文档作用域。视图配置页保留配置文件语义及删除视图入口。

## 配置、保存与兼容

在对象操作界面下创建视图：展开“人物列表”可看到人物关系网、人物关系网配置和“新建视图”；展开“关系类型”可看到关系类型网、关系类型网配置和“新建视图”。视图与配置是并列子项，配置不再嵌套在网络界面下。地图同样归属其源文件，聊天维持专用导航结构。

创建只编辑 JSON 中的节点与视图定义，不修改源文件 Markdown 或结构。创建后选中配置并展开源文件祖先；保存当前视图提交其配置及项目组织 JSON，不提交其他正文草稿。新建/拖动/配置修改进入同一 JSON 对象并自动存档；保存键显式导出配置文件。

视图 JSON 保存绑定和布局，世界文件保持平铺；创建不为集合建立实体目录。world-index 保存单世界组织清单，workspace.json 保存应用和组织状态。视图对象启动从 workspace.json 恢复。服务层 reloadCreationFile 有独立的视图 JSON 导入分支，会校验身份、绑定和布局；当前 AppRoot 刷新按钮针对视图源类正文，没有独立的配置 JSON 导入按钮。保存配置只写当前提交内容，不读取或合并旧文件。

旧 graph/map 配置和图节点通过 normalizeViews 转为默认父类与绑定，保留原布局/样式，不移动用户文件。改视图名同步树名称；删视图删逻辑定义，旧未引用磁盘文件尚未主动清理。地图改父类或删除来源后应面对失效引用，不凭旧名称猜对象。人物关系网父类固定为人物，旧自定义来源不再生效。

## 布局与性能

实际页面容器链必须 flex 填满剩余区、min-height:0，不能仅在独立组件中看似有画布；配置标题固定，正文独立滚动、居中。绑定控件和新建窗口统一主题。

documents 快照建立引用索引，投影/分组缓存不随平移、缩放或本地节点拖动重算。人物关系网本地预览位置，释放只提交一次布局，避免每帧触发全工作区保存及 Function 检查；绑定源数据修改仍实时重算。
