# 运行日志

日志记录当前应用会话中的程序信息、警告和错误，与世界数据和 Markdown 内容分开。关闭面板或切换页面不会清空记录；重启应用重新开始会话。

## 操作与布局

左侧导航底部在帮助按钮下、用户头像上放置 SquareTerminal 按钮。点击从底部滑出矩形日志面板，再次点击、点击面板外空白或按 Esc 收起，也可使用面板关闭按钮。

面板是覆盖层，左边界对齐 sidebar-region，横跨侧栏与 main-area 的底部，不覆盖左侧导航轨。rail 是最高层导航视图，日志面板及阴影均在它下方绘制。它不参与 flex 尺寸分配，不改变对象页或 Markdown 预览的宽高。高度为窗口高度的 45%，最多 360px；动画遵守减少动态效果设置，颜色使用当前主题。

## 记录内容

每条日志包含日期、毫秒时间、级别、来源和消息；异常可包含堆栈。支持文本搜索、按调试/信息/警告/错误筛选和清空。

归集入口包括工作区加载、JSON 自动存档、文件导入导出、Function/Tool 执行、工作流/Agent/模型状态、HTTP/SSE/图片请求、后台任务及格式校验失败。网络状态不记录 API 密钥或请求体；SSE 的逐字内容不重复写成逐字日志。原有界面错误提示继续显示，同时归集到日志。

主线程 Console、未捕获错误、未处理 Promise 拒绝和资源加载错误统一记录。JS/Flow Worker 的 Console 和任务堆栈回传主线程；Python 的 stdout/stderr 在执行结束后通过桥返回，失败时附带进程输出，不改变函数返回值。

## 性能与边界

当前会话保留最近 2000 条记录，连续相同消息合并并显示次数与最近时间。通知以 50ms 合并；关闭时不渲染日志行，查看旧内容时新记录不强制滚动。日志对象格式化限制深度、长度与数组项数，不执行 getter，不完整遍历世界快照。

Worker Console 每 250ms 最多转发 25 条，额外高频输出合并为计数提示，避免输出循环拖慢主界面。日志不写入 workspace.json 或 Markdown，不触发世界存档或改变业务任务的执行结果。

核心入口为 services/runtimeLog.ts，UI 为 ui/RuntimeLogPanel.tsx。业务调用可使用 appLog.info/warn/error、writeLog 或 logOperation；观察器失败不影响其他订阅者或业务结果。日志是诊断记录，不是跨重启的磁盘审计存档。
