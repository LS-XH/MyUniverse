## 实例名称编辑卡顿

需求：编辑 aria-label="实例名称" 的名称时，几秒后出现持续数秒的卡顿，要求定位并修复。

定位：名称每次变化会更新工作区，触发 400ms 自动保存、500ms Function 检查，另外还有 3 秒外部同步。只读测量当前 1760470 字节的工作区（1 个世界、10 个类、3 个 Function）发现，Function 检查有 107 项待更新任务，每个绑定字段重复计算全世界原始修订，引用依赖索引还按类重复建立；隐藏的 Markdown 列仍计算行定位并维护全文编辑 DOM，行号算法为每个字段反复截取并拆分全文前缀。这些同步工作叠加在 UI 主线程。合并和导出单项测量约为 6ms、14ms，不通过停止自动保存或取消外部冲突检查来规避问题。

修改：Function 调度在一次检查内共享世界修订、依赖索引和函数修订，跳过未绑定字段的输入转换；缓存不跨检查。结果重复提交返回原工作区，避免无意义保存/调度；自动任务按累计约 8ms 的时间片让出事件循环。仅改实例名时复用原字段，Schema 或字段变更仍进行同步。关闭 Markdown 预览不挂载编辑器、不算行位置；行定位改为换行索引，行数不变时复用编辑器 DOM，只改受影响行。

设计归属：[Function 调度](../features/functions.md#绑定调度与结果身份)、[文件操作界面](../ui/pages.md#创作文件操作)、[开发与验证](../development.md)。

验证：同一用户快照仅在内存进行只读运算，Function 检查约 154ms → 7ms，10 个类的源码行定位约 213ms → 6ms；没有执行用户脚本或修改用户数据。111 项测试通过，包含跨类 240 个绑定的修订一致性、下一次改名检查失效、旧结果拒绝和相同结果不重复更新。400 实例内存页面连续编辑名称通过，关闭预览时编辑器数量为 0；打开 4801 行源码后名称同步正确，再关闭仍保留名称。测量面板最近检查约 1.1ms、500ms 周期最大间隔约 891.5ms（包含界面自动化观察开销），不等同于桌面原项目的完整性能轨迹。前端类型检查及 Tauri release 构建通过，新 exe 在 target-next/release，当前正式程序占用文件，排队自动替换，不强制关闭程序。

## 工作流菜单焦点与变量拖动原卡片复用

问题：获取 Tool 卡片复制粘贴后选择注册项，快捷键持续失效；变量拖动时选值变为空提示、选中边框少一层、内部位置轻微变化。

根因与修复：原生 select 提交后仍持有焦点，而画布快捷键的编辑保护持续跳过 select。共享画布在提交下拉选项、拖动标题或点击空白后接回焦点，文本输入仍保留原生编辑语义。变量预览根元素 visibility:hidden 被克隆子元素 visibility:visible 覆盖，导致去掉 selected 且丢失原生选值的克隆盖住正式节点。普通画布移动不建立克隆，整体预览透明度归零阻止后代漏出；边界克隆同步原生输入控件当前值。

设计归属：工作流编辑器的节点身份、拖动形态和编辑快捷键章节，以及 UI 样式分类与复用中的画布边界规则。保留用户最新的 UI 家族表述与主题规则。

验证：116 项测试通过。内存页面复制粘贴获取 Tool 后更改注册项，焦点返回画布，删除 4→3 个节点、撤销 3→4 个节点。85% 缩放下真实拖动逐帧记录：绑定值始终 greeting，选中边框及 2px 外环保持一致，普通拖动克隆数量为 0，连线路径连续变化。自动化剪贴板拦截 Ctrl+C/V，因此复制粘贴步骤使用相同画布工具栏动作；删除与撤销使用键盘。未写用户工作区。

交付：文本参数获得焦点时 Delete 保留文本语义，节点数量不变。前端类型检查、生产构建和 Tauri release 构建通过；新 exe 位于 target-next/release，正式 exe 被运行中的应用占用，已排队自动替换，没有强制关闭应用。
