## 创作对象、列表与关系网

需求：以对象卡片表达实例和成员，统一引用、排序及关系编辑，支持整组选择、关系样式和源码定位。

修改：实例与 Schema 采用 Pointer Events 排序，完整占位挤位和释放提交；FieldCard 支持成员反馈；关系网支持多选/框选、边缘平移、有向箭头、真实关系和势力样式映射，批量编辑保留各自身份。居中内容列、固定标题/独立滚动、引用菜单 portal、只读 Function 结果与控件自适应逐步调整。

设计归属：[页面 UI](../ui/pages.md)、[投影视图](../features/interface-views.md)、[Function](../features/functions.md)。

原始详细记录：[Planning](archive/Planning.md)、[UI 原文](archive/docs/ui-interactions.md)、[设计原则原文](archive/docs/design-principles.md)。原文包含多轮尺寸、反馈和布局修正，相关早期描述后来被替代。

## 双栏、页面状态与主顶栏

需求：对象与 Markdown 同时可编辑、开关固定、恢复切页工作位置、树选择和展开分开、复用页面操作。

修改：Markdown 列与对象列真实分配空间，顶栏固定开关；源码定位、错误草稿与外部三方合并；PageSession 保留状态；箭头/双击展开，右键后续明确改为不导航；顶栏动作及资源管理器定位复用实际保存队列。

设计归属：[页面 UI](../ui/pages.md)、[存储](../data/markdown.md)。原文：[Markdown](archive/docs/markdown-sync.md)、[架构](archive/docs/architecture.md)、[Planning](archive/Planning.md)。

## 模型、Agent 与工作流基础

需求：将模型独立为导航入口，以共用画布接入 LLM、Agent 和 ComfyUI，并显式管理历史与变量。

修改：模型连接和目录发现、Agent DAG、ComfyUI API 图前处理/出图、HTTP Tool、异步原会话回复；后续编辑区优先、单工具栏、节点库收起、空白点击与平移分离。

设计归属：[模型与 Agent](../features/models-and-agents.md)、[编辑器](../ui/workflow-editor.md)。原文：[模型](archive/docs/models-and-agents.md)、[UI](archive/docs/ui-interactions.md)。早期 LLM 一体式行为现作为自动兼容卡片，新基础 LLM 规则由后续设计替代。

## 严格变量、观察与图标

需求：禁止新 ANY 变量，读写统一，Messages 保留 ToolUse，Image 维护资源，编辑与运行状态分开。

修改：五种初期变量、类型信封、成员目录、显式写入、成功提交记忆；多选/复制/撤销/双向连线；执行节点状态、边值和变量池；本地图标改为内联 Lucide SVG，避免 mask 色块。后续加入 Tools 并更改池布局。

设计归属：[变量类型](../data/workflow.md)、[编辑器](../ui/workflow-editor.md)。原文：[类型](archive/docs/workflow-types.md)、[模型](archive/docs/models-and-agents.md)。旧图标和独立浮动变量池描述不是当前规范。

## 对象投影视图与性能

需求：任意父类的数据可绑定关系网/地图，当前/固定路径分开、布局独立、无需移动世界文件。

修改：InterfaceView、view JSON/world-index、旧模板默认绑定、JSON 冲突保护；真实容器高度和主题控件；documents 快照索引和投影缓存，关系网拖动本地预览/释放提交。原文记录一次大量引用查询测量从约 744ms 到 4.01ms，仅为当时测量。

设计归属：[投影视图](../features/interface-views.md)。原文：[投影](archive/docs/interface-views.md)、[Planning](archive/Planning.md)。
