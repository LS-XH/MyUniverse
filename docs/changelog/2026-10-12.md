## 属性配置独立自动保存

用户指出：先在 MD 新增成员，再补充属性配置时，保存类正文会覆盖外部新增内容，刷新又可能恢复旧 Schema。将属性配置改为自动 JSON-only 提交，仅写结构、组织和工作区 JSON，保留已保存正文与其他草稿，不读写或验证 Markdown。属性页隐藏正文保存/刷新入口；Ctrl+S 只重试配置写入，正文刷新使用新配置。并隔离排队提交，避免旧投影回滚已保存的声明。

规范归属：features/persistence.md、data/json-storage.md、ui/pages.md；Planning 更新摘要。新增回归测试复现“先改 MD → 添加声明 → 刷新”过程，验证原文未被改写且新成员能读取。前端构建成功，199 项测试通过。

桌面 release 编译成功，已覆盖同名 my-universe.exe 并更新项目根目录快捷方式。

## 重复实例名错误定位

Markdown 解析的重复名称错误列出所有冲突实例名，并对多次重复去重；所有复用解析器的加载、刷新、导入及保存入口统一受益。新增多组重复名称回归测试。

### 属性筛选下拉样式补齐

Key、Value 原生 select 接入 ui-field--select，与 object-picker 共用主题背景、边框、字体颜色和圆角定义，补齐统一高度、焦点及禁用态。浏览器实测两者均为 36px 高、7px 圆角，禁用 Value 保留主题皮肤。

### 内容引用文本自动换行

text-reference-content 限制在父容器宽度内，其 textarea 使用 pre-wrap 和 overflow-wrap:anywhere：保留手动换行，连续中文及长链接按可用宽度折行。编辑与只读内容共用规则，不改写存储文本。

### 内容引用高度自适应

可编辑 Content 与只读 Content 共用 AutoGrowTextarea，首次加载、文本变化、宽度变化和字体加载后按实际 scrollHeight 更新高度；取消内部纵向滚动和最大高度限制，外层容器随之自然撑高，内容缩短时回收高度。保留引用编辑 ref 和光标，不改写文本。浏览器验证长文本 clientHeight=scrollHeight=858px、短文本收缩，外层同步变化且无横向溢出。
