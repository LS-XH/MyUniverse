# 修改日志历史原文

## 用途与边界

这里完整保留文档重整前的 14 份 Markdown，原始路径结构和字节不变，包含每次上下文补充、早期设计、旧验收结果及冲突描述。它们是修改日志的历史证据，不是当前设计规范。当前入口是 [Planning](../../../Planning.md) 和 [文档目录](../../README.md)。

原始相对目录保留，以方便阅读当时的文档互链；旧锚点或历史脚本路径可能原本就已失效，不在归档中修正。涉及代码请以仓库当前源码和设计为准。没有可靠时间的段落不补造日期。
