# 官方 Tool 模板与修改建议

更新日期：2026-10-10。

## 用户意图与注册方式

官方 Tool 是程序维护的只读对象，后续可以实现世界对象之外的功能，也可以由主程序为它们增加专门适配。它们不能修改、删除或移动，不作为用户脚本保存到 workspace.json。模型仅保存选择的稳定 Tool ID。

`model/builtinTools.ts` 定义冻结的官方配置，`registeredTools()` 将官方模板与用户 Tool 合并，保留 ID 命名空间 `builtin:`。即使外部配置写入同 ID 的伪造定义，注册和执行仍使用程序内的官方版本。`services/builtinTools.ts` 负责原生处理，不使用用户 JS 编辑器执行模板；查询复用主程序对象门面、类型转换和 Markdown 序列化。

工具页、侧栏、模型勾选及工作流节点都使用同一个注册表。官方模板页保留配置和测试浮层，配置字段禁用、无删除入口，主区域显示用途及 Schema。选择调用世界和填写测试参数属于调用上下文，不改变模板。新建的用户 Tool 仍可编辑和删除。

## 八个模板

参数名称为 JSON 属性；所有名称在当前调用世界内匹配，缺失或重名时明确报错。

| Tool | 调用名称 | 参数 | 返回 |
| --- | --- | --- | --- |
| 获取所有类名列表 | universe_list_classes | 无 | 类名称数组 |
| 获取类的成员实例结构对象 | universe_class_structure | className | className 和 members 属性结构模板，包含键类型、值类型、重复项、引用类及递归结构，不包含实例内容 |
| 获取类的成员实例结构 Markdown | universe_class_structure_markdown | className | 类标题、示例实例标题及嵌套属性标题；没有值、正文、派生结果 |
| 获取类的成员实例名称列表 | universe_list_instances | className | 该类实例名称数组 |
| 获取指定实例对象 | universe_get_instance | className、instanceName | 稳定 ID、名称、属性树及项目 TypedValue |
| 获取指定实例 Markdown | universe_get_instance_markdown | className、instanceName | 完整实例 Markdown，格式与现有序列化相同 |
| 查找实例子对象中的 key | universe_find_instance_key | className、instanceName、key | found 和全部 matches；每项包含稳定 ID 路径及类型化值，重名键不静默选第一个 |
| 提交实例修改建议 | universe_propose_instance_change | className、instanceName、markdown | proposalId、pending 状态；不表示世界已修改 |

第 2、3 项按类的 schema 生成“实例结构模板”，不是枚举已有实例内容。第 7 项对实例属性树深度优先精确匹配键名；空值与未找到通过 found 区分。

## 用户确认修改

第 8 项按用户确认只使用三个参数：类名字、实例名字、修改后的 Markdown 内容。markdown 使用第 6 项返回的实例格式，以 `## 实例名字` 开始，保留实例名字和类结构。复用现有 Markdown 解析器校验，禁止同时修改其他实例或类 schema。

执行只发出 `onInstanceProposal` 程序事件。聊天处理器在对应世界、对应会话追加持久化建议卡片，展示修改前后 Markdown，并提供“保存修改”和“拒绝”。模型调用携带原会话 ID，切换世界或聊天后也不会把建议插入错误的会话。工具页测试时建议进入调用世界的当前聊天，没有聊天则创建“实例修改建议”会话。

用户确认前不修改实例。确认时重新检查类与实例存在、类规范未变化、实例内容仍与建议生成时一致，重新解析 Markdown，保持原稳定 ID，并仅替换目标实例。变化时拒绝覆盖，提示重新生成建议。拒绝仅修改建议状态；已处理建议不能重复提交。建议及状态存入原聊天 JSON，重启后仍可查看。

保存修改更新主程序内存，随后由原有自动存储流程保存，仍有同步错误和冲突提示。聊天里的“已保存”表示已采纳到主程序状态，磁盘失败由统一同步提示显示。模型收到 pending 后必须等待用户操作；后续聊天请求会包含建议状态，不能将 pending 描述为已经修改世界。

这些模板声明只读，因为查询不写世界，建议 Tool 只发出确认事件。此声明不改变用户 JS Tool 的独立运行规则，也不新增外部 MCP 服务器或网络传输。

前端生产构建和桌面构建通过。当前桌面程序占用正式 exe，交付脚本已排队自动替换；关闭当前程序后安装器替换同名 exe 并更新快捷方式，不强行终止正在运行的程序。
