# 工作流结构与交互规范

## 侧栏、端口与画布布局

1. 变量池与节点库共享侧栏父容器。变量池从侧栏底部展开，挤占节点树的可用高度；展开按钮随高度滑动到池的右上角。标题右侧依次是新建变量、清空全部值、收起。类型选择背景及文字取当前主题。变量卡片支持拖出、排序挤位、删除及清空值。
2. 端口分输入、输出和同语义输入输出。输入输出合并为 flow-input-output-row，保留两端连线；端口行悬停显示细强调边框和浅发光，内嵌变量悬停突出。变量拖入端口成为一行嵌入引用，拖出恢复变量卡片。输入绑定读取，输出绑定写入，输入输出绑定先读后写。普通方法仍只产生值，只有显式连线写变量或绑定输出才保存。
3. 卡片及空白画布支持同一组右键操作，复用顶部复制、粘贴、剪切、撤销、重做及删除；空白时复制、剪切、删除禁用。
4. 原 LLM 卡片保留兼容行为，固定名称改为 LLM 模型（自动 ToolCalls）。新增基础 LLM：只输入 Messages 与 Tools，只请求一次并输出 assistant Messages，不追加隐藏系统词，不执行工具。系统词由 Messages 管理。ToolCalls 卡片接收 Messages 与 Tools，执行未返回调用并输出所有 role=tool 的 Messages；合并、保留轮次、再次调用 LLM 均由显式节点编排。
5. 配置与运行浮层位于节点库左边，节点库关闭时位于画布左边。点画布空白关闭，不能遮住节点库。
6. 变量类型 Tool 重命名 Tools，包括变量信封、值标签与端口；旧数据显式兼容迁移，具体 Tool 定义和调用名称不变。
7. 类型目录使用类型图标，Tools=wrench、Messages=messages-circle、Number=hash。
8. 每个端口行显示类型图标。节点库悬停右侧动画显示“输入图标 → 输出图标”，顺序与端口定义一致。

卡片名称是类型固定属性，不能根据实例用途自行命名；变量名、模型选择、Tool 选择属于卡片内参数。

## 拖动形态与参数槽

拖动遵循不变性原则，按上下文转换而非按对象种类一律缩小：

| 所在区域 | 预览形态 | 松开后的行为 |
| --- | --- | --- |
| 节点库、变量池 | 行卡片 | 保持列表；变量池显示动画挤位并保存排序 |
| 暴露的画布 | 变量保持完整卡片；节点库新建对象显示目标尺寸占位矩形 | 创建节点，或移动原变量节点 |
| 其他节点卡片内 | 动画收缩为行卡片 | 未进入兼容参数槽不建立引用 |
| 类型兼容的参数槽 | 行卡片吸附到槽位 | 建立输入、输出或输入输出引用 |

画布变量和普通节点统一使用 useCanvasEditing 的移动、选中及撤销事务，每次移动更新节点坐标，端口位置及连线同步更新；禁止用独立 DOM transform 代替普通节点移动。变量只额外注册边界回调，进入其他卡片或列表时暂停普通移动并切换形态，不留下原位虚影。行小卡片复用 flow-palette-item。

从节点库离开列表时，行卡片变为不含内容的卡片占位矩形，使用主题 accent 虚线边框及 active 选中背景；返回节点库恢复行卡片。占位长宽必须与即将创建的真实卡片一致。Agent/SD 和 Function Flow 各自抽取唯一 renderNode，useDragCardSize 在隐藏测量容器调用同一个渲染器取得原始尺寸，不能根据端口数量估计高度或另写预览内容。

所有拖动预览先在原始尺寸下布局，再通过整体 transform scale 缩放。文字、图标、边距、边框、宽高必须共同变化，禁止只调整外框宽度造成重新换行及高度失真。画布及其父卡片中的行预览、完整变量预览、填入引用均使用画布比例；固定侧栏中的行预览使用侧栏原比例。外层负责屏幕坐标和占位尺寸，内层负责统一缩放，不能重复缩放内容。

吸附始终保留同一个拖动外壳：连续改变位置、宽高、主题颜色及内部内容，使行卡片变成填入槽位的 flow-inline-variable，不使用两个对象淡出／淡入替换。槽内临时引用只占据最终布局空间，拖动对象变形到其准确位置；松开后由正式引用接续。鼠标未松开时仍处于手势中，拖离槽位撤销临时填入，恢复行卡片或完整卡片。临时引用不改绑定、连线、变量值和运行记忆，松开才提交且必须匹配声明类型。

flow-inline-variable 是 flow-palette-item 的紧凑版本，无边框和额外背景色。悬停向屏幕外突出、按下回弹，表达可拖动交互；动态效果遵循主题与减少动画设置。

仅 String、Number、Boolean 端口允许直接填写值。Messages、Image、Tools 等非基础类型使用带类型提示的变量投放槽，不提供 JSON 文本编辑框；也可通过连线输入。已有连线显示只读来源。端口行左右留白、上下间距及连接值宽度应保持紧凑，不铺满卡片。所有输入、输出及合并端口行悬停使用细强调色边框和浅强调色发光，不放大或突出、不改变布局；内嵌变量仍使用突出反馈，以区分参数行与可交互变量。

## 执行边界

变量引用保存稳定变量 ID 及名称，用于重命名、复制和持久化。引用与连线不能同时占用一个输入；绑定时替换输入连线。绑定输出也必须满足声明类型。所有局部变量写入在运行副本中，失败不提交 Agent 记忆；已有工具对世界或网络产生的效果无法回滚。节点执行仍是无环依赖图，通过 after 明确副作用的先后顺序。

基础 LLM 的一次返回和 ToolCalls 的工具结果是消息片段。工具结果片段不能直接作为完整对话发送，应与原 assistant ToolUse 合并，保证 tool_call_id 配对。自动卡片与显式节点并存，避免升级改变已有 Agent 行为。

## 实现状态

Agent/SD 共用 WorkflowEditor、WorkflowPorts、VariablePool、useVariableDrag；拖动外壳由 DragCardPreview 统一维护。Function Flow 共用拖动形态动画、端口悬停样式、类型图标、节点库签名与右键菜单。Function Flow 自身使用函数输入与代码块数据，不添加 Agent 世界记忆池。

### 变量引用与池操作

WorkflowNode.bindings 使用 `in:端口` / `out:端口` 键，保存 `{variableId,name,output?}`。同语义配对由 workflowBindings.pairedOutput 的类型定义决定，不能仅因类型相同就合并。例如 Messages.user 的 self/value 配对；Messages.count 的 self/value 保持分开。拖入合并行明确读写引用，拖入独立输出仅写入。再次连线替换输入引用，拖出引用移除绑定并创建对应类型独立变量节点，池定义始终保留。

变量顺序以 graph.variableOrder 的稳定 ID 保存，不依赖数字对象键排序。预览按手势起始位置计算插入点，避免挤位动画干扰。取消不修改图，放到被浮层挡住的画布不添加节点，预览保持来源可见宽度。删除同步移除对应变量节点、关联连线、嵌入引用及各世界记忆。清空恢复声明类型默认值；修改初始值或清空同步重置各世界已有运行值，避免恢复旧值。

### 消息与工具分工

llm 保留兼容自动交流，名称为“LLM 模型（自动 ToolCalls）”。llmBasic 为“LLM 模型”，输入 messages:MESSAGES 和 tools:TOOLS，输出 value:MESSAGES，仅含本次 assistant 响应。不使用模型默认 toolIds、不注入系统词、不执行工具；不接 tools 即不提供工具。未配对的 ToolUse 或孤立工具结果不能直接作为其完整输入。

toolCalls 执行 Messages 中尚无返回的全部调用，按所接 Tools 校验工具名称与参数，逐一输出 role=tool 消息。结果为 `{type:"Messages",version:1,fragment:"toolResults",items:[...]}`，只允许唯一 tool_call_id 的工具返回。基础 LLM 不直接接受该片段；Messages.merge 与原 ToolUse 合并后校验完整配对。已返回调用不重复执行；工具错误产生配对的 isError 返回，取消终止运行；ToolCalls 不再次请求模型。

自带示例改为：Messages 初始值管理 system → 保留最近 8 轮 → 添加 user → 基础 LLM → 合并 ToolUse → ToolCalls → 合并工具返回 → 第二次基础 LLM（不提供工具） → 合并最终回复 → 显式保存 Messages → 最后文本返回。它展示一次工具交流；多步迭代需继续显式编排，当前图仍无环。

### Tools 与主题

新值为 `ToolsValue={type:"Tools",version:1,toolIds:string[]}`，信封 `{id,type:"Tools",value:ToolsValue}`，端口 TOOLS。workflowMigration 在加载、编辑和执行时迁移旧 Tool/TOOL 标签，包括 Tools 端口本地 JSON 值，不改写世界正文或自由参数。具体 Tool、注册 ID、MCP 调用名称不变。

类型菜单通过 portalTheme 继承触发按钮所在主题，解决渲染到 body 后丢失主题。新增颜色取 panel/input/text/muted/border/hover/active/accent；Number=hash、Messages=双圆消息、Tools=wrench。动画尊重减少动态效果设置。

### 验证

110 项测试通过，覆盖引用读写、重命名、类型错误、清空/删除与记忆同步、排序身份、失败不提交、基础 LLM 单次请求、ToolCalls 工具结果配对及旧数据迁移。模拟模型响应执行真实官方查询，不使用用户密钥。

浏览器内存页面验证了：池挤占节点树、主题菜单颜色、排序、嵌入/拖出、实际 String 引用读写（hello → HELLO）、清空与删除、空白右键禁用、节点类型签名、浮层避让、收起节点库后浮层移到左边、点击空白关闭；非基础参数槽没有文本编辑控件，端口留白及行间距生效。拖动逐帧观察记录验证变量移动时端口位置和连线路径持续更新，兼容槽存在临时布局及同一拖动外壳的填入状态，最终引用边框为零且背景透明。节点库占位预览为空内容、强调色虚线和选中背景，85% 缩放下测量值 300 × 247.6 对应预览及正式节点 255 × 210.46，另一缩放比例也随整体尺寸变化。真实模型和 ComfyUI 需使用用户配置的服务验收。

前端生产构建及桌面 release 构建通过。当前程序占用正式 exe，自动替换已排队，关闭当前程序后生效。清空命令通过编辑事务携带临时 resetNames，强制重置运行记忆，即使初始默认值未发生变化；该指令不写入工作流文件。
