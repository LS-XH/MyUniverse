# 页面与通用交互

本文件按页面与对象分类。跨页面理由见 [设计原则](design-principles.md)，工作流卡片和变量拖动的细节见 [工作流编辑器](workflow-editor.md)。

## 应用框架

### 导航与路径

最左侧主导航为创作 PencilLine、插件 Puzzle、模型 Sparkles、设置 Bolt。侧栏可收起，按钮固定在主区边缘；各页面会话独立恢复。树使用缩进和 ChevronRight/ChevronDown 表达层级，不绘制层级线。

单击名称打开操作页；22px 右侧箭头或双击名称展开/收起。叶子不显示无效箭头。世界项目直接作为顶层节点，单击打开该项目的集合列表。右键只设置菜单目标，不调用树行 click，不切世界、页面或主题；选中命令后才导航并复用实际动作。

主顶栏 breadcrumbs 标识当前路径。插件显示插件 → 技能/函数/工具 → 全部父文件夹 → 当前项；模型显示模型 → LLM/SD/Agent → 当前项。创作显示世界及当前对象/配置。名称变更同步展示。

### 顶栏与页面动作

主顶栏以 20px 图标及悬停提示展示页面动作，固定 Markdown 开关位于最右。顶栏读取页面真实动作，保留禁用、开关、导入和确认行为。文件夹页保留原动作组，具体编辑页避免重复的大标题和创建区。

工作流只保留一条 flow-toolbar，脚本保留 editor-toolbar。页面级导入/导出、删除文件等移至主顶栏。编辑工具栏负责配置、运行、视图和图编辑。

### 页面会话

PageSession 按对象 ID 保存滚动、树/成员展开、搜索、画布视角、倍率和面板状态。会话不是持久业务内容；切页恢复位置。关系网打开具体实例时清空名称过滤，使对象可见，并短时定位高亮。

## 创作：项目、集合与树

项目列表与集合页面显示对象卡片和新建入口。集合可创建子集合、类文档与界面操作类型；创建关系网/地图必须选择父文件类型。默认模板的保护对象没有删除入口，普通项保留删除确认。

### 树卡片拖动

世界可排序；同一世界中的集合、文件和界面可排序或移入集合。插件文件夹、Function 和用户 Tool 可在本分类内混排与更换父文件夹；模型项在自己的类型集合排序。分类根、附属配置、会话和官方 Tool 保持固定归属。

按名称拖动超过阈值后，出现保持来源可见宽度的跟随卡片，无额外边框；原项及子树让出占位，其他项动画挤位。目标上下边缘表示之前/之后，文件夹中间表示移入。禁止跨世界/分类、移入自身或后代。边缘自动滚动；空白无效落点、Esc、失焦和指针取消不提交。

释放仅改组织与顺序，不改原 ID、内容、引用和磁盘位置。插件混排存 sidebarTreeOrder；虚拟集合不生成物理子目录。实现：useTreeDrag.ts、treeMoves.ts。

## 创作：文件操作

### 手动保存与刷新

保存当前文件、刷新及保存全部只放在右上角，不在 instance-edit-actions 重复显示；Ctrl+S 和 Ctrl+R 在整个创作区生效，即使文本框或 Markdown 编辑器正在输入。保存先处理待解析源码，错误草稿阻止写入；刷新会放弃当前文件未保存修改，从持久化内容读取并计算全部绑定函数。计算结果仍需明确保存。顶部复用保存/刷新动作，最右上角固定 SaveAll 图标保存所有文件；Markdown 分页按钮在其左侧，分页标题为按钮预留位置。

树中未保存文件名右侧显示主题色发光圆点，父集合和世界汇总子项状态；新建、删除、排序与函数添加也属于未保存更改。保存成功按实际提交快照清除，其他草稿或保存请求期间的新编辑保留圆点。切页保留主程序草稿，不保存或计算函数。

### 实例与搜索

文件页标题显示类名，旁边加粗 + 新建实例，无独立实心圆底。名称直接编辑，悬停/聚焦显示 PencilLine。标题固定，entity-list 独立滚动；实例卡片提供展开、删除和拖动手柄。

实例仅改名时保留原字段对象；Schema 和字段未改变，不重建全部实例成员。名称实时更新主程序草稿，不自动写盘或执行函数；明确保存直接序列化当前快照，不读取正文。

名称搜索与 h1 在宽屏同排、垂直对齐，水平中心以整个 page-heading 为基准；实例操作按钮在同一行右对齐，独立于搜索框位置。标题、搜索和操作共用三列网格，两侧等宽，搜索标准宽约 640px；窄空间搜索换到独立居中行，操作仍靠右。实时过滤并支持清空，搜索状态随页面恢复。无匹配使用轻量图标、说明和清空入口，无 empty-card 外框；首次未创建实例保留创建引导。

实例排序使用 Pointer Events 和 SortHandle：同宽跟随副本、完整占位、邻项挤位、自动滚动、Esc 取消、方向键排序。释放后更新草稿，明确保存时同步 Markdown 实例顺序。

实例卡片单击使用主题强调色高亮，Ctrl 单击追加/取消，Shift 从空白或卡片非编辑区域拖动框选可见相交实例，Ctrl+Shift 追加框选；空白单击取消。输入、按钮和拖动手柄保留原交互，文字编辑快捷键不被实例操作抢占。

搜索右侧的 icon-button、共享右键菜单及快捷键使用同一组实例命令：复制 Ctrl+C、剪切 Ctrl+X、粘贴 Ctrl+V、删除 Delete、撤销 Ctrl+Z、重做 Ctrl+Y / Ctrl+Shift+Z、添加标签。无选择时禁用复制/剪切/删除/标签；空白右键清除选择。实例剪贴板在应用内按类身份使用，跨类结构不匹配时提示，不把陌生字段写入目标类。副本为实例及所有递归成员生成新 ID、保留 schemaId，按原顺序插在最后一个选中实例之后；无选择时追加末尾。剪切和删除可撤销。历史限定当前文件页面，外部真实变更清空历史，避免撤回远端内容；不撤回 Function/模型等外部副作用。

标签是实例卡片的样式颜色，一次选择一个标签，多选实例可批量添加或清除。属性配置在属性结构下方提供“标签配置”，复用 Schema 行、排序手柄及关系网 ColorPicker；标签可改名/颜色或删除，删除同步解除实例关联。颜色浮层通过主题 Portal 挂载到页面，避免属性行悬停 transform 改变固定定位。定义与关联存 ClassDocument JSON，不进 Markdown。

### 成员卡片与值控件

每个 Key/Value 组成 field-card，函数添加成员复用同一结构并以只读模式显示，Object 子成员递归嵌套。成员编辑不绘制层级线，以缩进及卡片边界表示归属。悬停约 1.008 倍从中心突出，保留阴影和主题高亮；最内层响应，不叠加父级放大，不使用三维旋转，不向上平移改变占位。动画在局部 UI 完成，不写世界。

短文本默认约 240px，随内容增长到容器上限；Content 多行保持宽幅。引用按钮自然宽度，派生来源选择与 Value 优先同行，空间不足才换行。添加成员、子成员和重复项使用完整无边框圆角命中区，悬停/按下渐变、键盘焦点可见。

### 引用与菜单

Text/Content 输入 # 按实例名称或类名称搜索，在光标附近插入 Class Markdown 引用。Class 类型键和值使用同一世界选择器；动态返回值来源选择复用引用控件。下拉菜单通过 portal 定位，不受卡片裁切，背景与前景继承主题。

引用遵循稳定身份与声明类约束，展示名称不承担唯一身份。来源失效或循环要显示错误，不能静默使用错误对象。

### Markdown 双栏

主顶栏固定 PanelRight 按钮控制独立源码列，源码标题区与顶栏连续；动作组随列宽让位，开关不左右移动。源码列按宽度/透明度渐变，文件主区为其分配空间。空白点击或字段编辑不关闭源码；按钮或 Esc 可关闭。

字段编辑与源码双向关联，选中名称/键/值可定位对应源码行，使用主题 markdownHighlight。标题按层级加粗，围栏内标题不采用标题样式。非法草稿保持编辑状态，不覆盖有效对象。解析、保存和冲突细节见 [Markdown 与存储](markdown-sync.md)。

源码列关闭时保留草稿与选择状态，但不挂载全文编辑器、不计算源码行定位。打开后从当前对象恢复内容与高亮。行定位先建立全文换行索引，避免为每个字段重复截取并拆分全文前缀；预览行数不变时复用现有文本行，只更新变化的文字和样式，不因改一个名称替换整篇 DOM。

### Function 添加值

绑定函数为 void，通过统一 add 接口填写实际成员；生成成员使用普通键值控件，但键/值为只读，引用选择器禁用，生成子树不能添加或删除；关系详情和批量修改同样保护。每个生成成员上方显示加粗的“函数名 →”，不创建函数名成员或专用只读返回框。完整来源保留内部标记，解绑、换绑、删除函数时清理。执行错误为提示而非成员值，完整生命周期见 [Function](functions.md)。

## 创作：属性配置

居中内容列配置 Key 类型、名称/引用类、Value 类型、提示文本、可重复项、Object 子结构和 Function 绑定。Const 在配置中编辑常量名，Class 选择引用类。文件编辑与配置共用 FieldCard 反馈，但职责分别是填写内容和定义结构。

schema-grip 与实例共用 SortHandle，同一父对象内上下排序，子项不跨父对象。Object 随父行整组移动，释放同步 Schema 与实例字段顺序。采用指针事件，避免桌面 WebView 原生文件拖放拦截。

文件与 Schema 使用适度留白的居中布局，参考最大宽度分别约 1180px 和 1280px；内部控件依内容扩展。Markdown 开启后按剩余宽度适配，不简单遮挡内容。

## 创作：关系网、地图与聊天

### 关系网

全区画布显示人物实例、方向关系及势力背景；右侧详情浮层可收起。默认选择状态，空白左拖平移、Shift 框选、Ctrl/Shift 点击多选，拖任一已选节点移动整组。空白单击清选择，平移保留选择。缩放围绕光标，支持 8%–300%；拖动边缘自动平移，仍可滚轮缩放。

连线模式可开关，支持先选起点或依次选择两节点，半透明预览跟随光标，Esc 退出。箭头主语是保存关系字段的实例，目标为引用对象，不自动反向添加。SVG 范围随节点和预览变化，支持负坐标。线与箭头使用配置填充、外边框、线宽和间距，悬停按原样式增强。

工具栏分别控制关系文字与函数生成关系的显示。重复关系值逐行显示，关闭函数生成关系后仅保留手动关系及其手动值；完整规则见 [关系网投影](interface-views.md#元素与关系上下文)。

默认卡片约 210×88px，头像约 52×56px，姓名与副标题优先可读。关系网仅用于人物类别；姓名、首字头像与势力地位按人物结构读取。多选详情只提供唯一匹配的共同成员，混合值明确标识；修改保留各自字段 ID 与未选内容，不猜重复项。

### 视图配置

标题固定、内容独立滚动并居中。人物关系网不显示父文件类型、显示元素绑定或连线标签来源，保留关系和势力样式配置；地图继续显示父类及元素绑定。关系/分组样式用真实实例作映射键，新增只列尚未映射项；参数优先同行，窄窗口换行。颜色使用统一 ARGB 选择器。绑定、写回和布局契约见 [投影视图](interface-views.md)。

### 地图

地图填满剩余操作区，背景和标记来自对象绑定；可平移、光标缩放、拖标记并打开源实例。标记布局覆盖仅保存在该视图，不自动改源坐标字段。图例与配置使用当前主题。像素地理坐标不是经纬度 GIS 契约。

### 聊天

无会话时输入区居中，有会话时消息填满主区、输入区在底部。新建、切换和删除会话在创作树下完成，不增加独立会话页面。输入区左下角统一分组选择启用模型/Agent；Schema 不符合 input 字符串直接调用契约的 Agent 显示禁用原因。模型配置分别提供接入工具和接入子 Agent 的主题卡片，显示名称、说明、选中数量和停用状态；停用项不能新增接入，已选项可解除，删除项可清理失效接入。子 Agent 可使用自定义 Schema，由模型生成参数，不受聊天直接选择 Agent 的 input 契约限制。选择 Agent 无需另选模型，首次发送创建会话。阅读位置距消息底部超过 64px 时，在输入区上方居中显示圆形下箭头按钮，点击回到最新消息；滚动回底部自动隐藏，减少动画偏好时直接定位。离开底部时新流式内容不抢走阅读位置。右下角只保留一个发送/停止按钮：空闲时发送，运行时原位切换为停止，取消仍保持可点击。

请求由 AppRoot 管理，切页仍写回原世界/会话；失败/取消保留已显示过程，停止中止 SSE。文字实时追加，思考与工具详情折叠，子 Agent 按调用树嵌套，节点和循环放入过程区。进度展示节点实际名称及可读循环轮次，不展示内部节点 ID 或缓存 frame 路径；名称随事件保存，旧记录优先从对应 Agent 图恢复，否则显示步骤序号。失败后未结束的循环同步为失败/取消，不保留运行中。官方修改建议展示带单列行号/上下文的 Git 风格差异，使用主题 success/danger 色，右下角“保存修改 / 拒绝”；pending 不表示世界已修改。过程折叠卡片使用主题面板、图标、状态徽标与展开箭头，官方工具显示中文名称。实例建议默认收起，摘要展示对象名称、状态和全部新增/删除行数；展开查看差异及保存/拒绝按钮。相邻同类新增/修改提议默认合并折叠，提供全部保存/全部拒绝，已保存提供单项回退和组回退；批量失败不部分提交，冲突提示保持原状态。连续工具调用默认合并为可展开工具组，显示次数与组状态，组内保留各调用详情；正文、思考、建议或子 Agent 分隔组，不跨调用作用域合并。差异正文自动换行，连续编码与无空格长文本也不得撑宽页面，行号列保持对齐。助手最终正文、流式正文及服务返回的思考内容使用 Markdown/GFM 渲染，支持标题、列表、引用、表格和代码块；工具 JSON 与差异保持原始文本。用户消息下方显示主题编辑、复制图标。编辑填回输入框，可取消；确认重新发送时替换该消息并重新生成后续对话，已采纳的世界修改不回滚。生成时禁用编辑，复制仍可用；复制原始文本并显示成功/失败反馈。用户消息按纯文本展示，保留用户主动输入的换行，不额外插入前导空白。消息协议与建议规则见对应功能文档。

## 插件页面

技能、函数、工具按分类树和虚拟文件夹组织。集合页面以卡片浏览，具体编辑页以源码或 Flow 为主。Function 标题为“函数 - 子类型 - 名称”；Flow 与模型画布标题必须显示对象名。

Tool 与 Function 共用紧凑工具栏、全高代码编辑器和对象调用助手。配置/测试浮层默认关闭且互斥，独立滚动，不挤压源码；MCP name/description/Schema/annotations 在配置内。HTTP 请求设置亦在配置中。官方 Tool 字段禁用、无删除动作，调用世界/测试输入可填写。

Function 配置取消返回类型选项，代码助手提供 add 补全与速查；测试选择具体绑定成员并展示执行状态，错误只作提示。测试写入与绑定协调的边界见 [Function](functions.md#执行环境flow-和编辑)。

Skill 执行与插件安装界面尚待实现；Function/Tool 运行契约见 [Function](functions.md) 和 [脚本与 Tool](script-runtime-and-tools.md)。

## 模型页面

模型独立于设置，分类为 LLM、SD、Agent。连接页配置 URL、模型目录、参数和注册 Tool；工作流页填满主区，显示对象名称；配置、运行与节点库共用工具栏下方的右侧停靠区，切换时只显示一种内容，画布让出宽度，面板内部独立滚动。Agent/SD 与 Function Flow 的交互由 [工作流编辑器](workflow-editor.md) 统一维护。

## 设置与主题

预设为星雾蓝紫、经典暗黑、晨光浅色，只读；可复制、新建、命名、删除自建主题。颜色覆盖 rail/sidebar/surface/canvas/panel/input/border/text/muted/accent/hover/active 及图、聊天、标记、源码高亮等专用对象。使用 ARGB 选择器及 8×8 方形色板，选择预设保留当前透明度。

导航、滚动条、下拉、右键、弹层等必须应用语义主题颜色。减少动态效果下保留反馈但停用位移/旋转。部分底层样式仍有早期色值，新增/维护样式应使用主题覆盖，不将残留实现描述为设计许可。

## 打开文件位置

桌面主顶栏 FolderOpen 在一次统一保存完成后定位实际对象。文件页指向类 .md，属性配置指向 .schema.json，视图配置指向对应 JSON；世界/集合指向世界目录，项目/模型/Tool/主题指向 workspace.json，Function 指向 functions 中的脚本，插件文件夹指向 functions 目录。无独立内容文件的操作画布不显示定位按钮。

浏览器禁用并提示桌面可用。后端限制在 user 内，拒绝非法路径、缺失文件和解析后越界链接。同步冲突和定位失败沿用统一提示，不跳过保存保护。

## 公共 UI 皮肤

控件使用同一 CSS 家族基础，差异由显式变体和局部变量表达。普通 ghost、标题按钮、顶栏图标、两类右键菜单保留不同的按下反馈；FieldCard 放大高亮、端口和拖动仍由各自交互实现。主题含可编辑的 danger、success、warning；Portal 继承触发区主题。映射与边界见 [UI 样式指南](ui-styles.md)。

### SD 工作流画布性能（2026-10-11）

视角平移与缩放只更新 stage transform，不应重建 ComfyUI 节点库或逐个测量全部端口。节点库按 catalog、查询和展开状态缓存，节点控件按图/选择/运行状态缓存。端口坐标在 stage 本地坐标系计算；图或节点尺寸改变时通过 requestAnimationFrame 合并测量，坐标未改变不更新状态。

普通节点拖动使用本地预览，松开时一次提交，并作为一次撤销事务；取消丢弃预览，不保存或增加撤销项。变量卡片的跨区域拖放继续交给变量绑定逻辑。参数与连接编辑继续走原保存路径。内存浏览器以100个画布节点、500个目录条目验证拖动一次提交，以及撤销、重做位置恢复。

### 人物关系聚焦

关系网双击人物显示个人关系网，中心人物周围仅排列其直接关联人物。左上角返回或 Esc 退出并恢复原视角。个人模式继续支持平移、缩放、选择及拖动，布局与完整关系网隔离。关系连线格式与背景块格式默认折叠，关系格式每项前方的勾选开关控制对应关系类型的可见性。

### 实例与树视图的未保存标记

文件操作界面的实例卡片在名称右侧显示主题色发光小圆点，按该实例与最近成功保存的快照比较；名称、成员内容、函数生成内容、标签或排列位置变化以及新增实例均可触发标记。其他实例的改动不会让未改变的实例同时显示标记。撤回到已保存内容或成功保存后，标记随比较结果消失；保存期间的新改动仍保留标记。

树视图继续在文件名右侧显示发光小圆点，并向父集合汇总未保存状态。标记不改变原有文字的字号、字重或布局规则，名称样式不依赖它是否为最后一个子元素。

### 创作项目的顶层排列

创作侧边栏不再显示“我的项目”父菜单，各世界项目直接作为顶层树节点，保留独立的展开按钮、双击展开、右键操作和未保存圆点。创建世界与项目顶层图标使用相同左侧间距，整体左移；子项仅相对所属项目缩进，不保留被移除父菜单的竖线或缩进。

### Markdown 的行差异与选中对象

右侧双栏 Markdown 同时展示当前正文与最近成功保存快照的行差异：新增行使用浅绿色背景和行首 +，删除的旧行使用浅红色背景和行首 -。删除行只作为只读对照，不参与正文编辑、解析与保存；增删符号是界面标记，不写入文件。当前选中的实例或属性及其下级内容使用浅蓝色背景，覆盖同一区域的差异背景，行首差异符号仍保留。

差异展示保留全文，不折叠成提交摘要。保存成功后使用新的已保存快照比较，未再次修改的增删标记消失；刷新读取的文件成为新比较基线，刷新后函数追加内容仍表现为未保存新增。新增文档以空基线显示新增行。原有直接编辑、输入法输入、标题字号和定位功能继续生效；三种背景色可在主题中配置。

## 手动持久化边界

全部界面操作先修改内存 JSON；设置、插件和模型也不自动保存。正文仅在启动及明确刷新时读取，保存只写当前对象，不读取或合并 Markdown。Ctrl+S/Ctrl+R 用于当前文件或配置，保存全部统一提交。函数提交和脚本保存请求不隐式写盘。未保存标记比较序列化内容与成功读写基线。完整规则见 [Markdown 与存储](markdown-sync.md#手动读写边界与版本基线)。
