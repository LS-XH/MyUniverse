# 通用设计原则

本文件只维护跨页面规则。具体布局归 [页面 UI](ui-interactions.md) 和 [工作流编辑器](workflow-editor.md)，具体数据契约归 [数据模型](data-model.md)。

## 对象与表示

### 同源对象

文件、关系网、地图、Function、Tool 都通过同一个世界数据模型读取。Markdown 是对象的可读表示，视图是对象的投影；不能分别维护互相脱节的内容副本。配置与布局可以独立持久化，内容身份仍指向源对象。

导航归属、数据来源、运行状态和界面会话分别管理。树位置不改变文件路径，视图 parentClassId 不等于导航 parentId，缩放与滚动不触发内容修改。

### 明确类型和提交边界

世界成员类型、Function TypedValue 与工作流变量类型分别校验。禁止以 stringify 掩盖封装类型差异，Tools 不接受普通 ANY 值冒充身份。

计算和保存分开：方法输出新值；变量保存需要显式 value 连线或输出绑定。脚本修改世界先通过会话草稿校验与合并；Agent 记忆整次成功才提交。已发生的网络、工具世界修改或图片保存，不随图撤销或局部记忆失败而回滚。

### 绑定函数的非破坏性扩展

绑定函数只通过 add 扩展已有结构中的可重复成员，不能改写既有值或越过引用写入其他实例。生成成员与用户成员共享控件外观，生成内容由函数维护，用户操作只读，以“函数名 →”提示来源，并保留内部所有权，用于绑定失效后的清理；用户不得修改生成键值、子树或直接删除；持久来源和执行状态用于复用已有内容，不靠每次编辑重算来辨认来源。原子提交、自身生成不触发递归重算及兼容边界由 [Function](functions.md) 统一定义。

## 布局与操作载体

### 内容决定宽度

列表与配置页面使用居中、适度留白的内容列；短文本、引用、数字控件按内容扩展，不无条件占满整行。宽度不足时换行或按页面规则滚动。工作流和代码编辑页则填满主区，将空间优先留给编辑载体。

Markdown 双栏是布局的一部分，按列分配空间；主顶栏固定按钮不随列移动。节点库与变量池共享侧栏容器，通过高度分配形成真实布局；配置和运行浮层必须避开库所在区域。

### 页面职责和命令复用

集合页负责浏览和创建；对象编辑页负责当前对象操作。顶栏、右键、工具栏调用同一组业务动作，保留实际禁用、确认与导入行为。

单击打开页面，箭头或双击展开树。右键只记录菜单目标，不改变世界、页面或主题；执行菜单命令才导航并调用目标操作。卡片标题固定于类型，变量名等用途信息放在参数中。

## 主题与控件

### 颜色归主题

普通界面使用主题的 panel/input/text/muted/border/hover/active/accent 等语义颜色。关系网等提供独立颜色配置的视图可使用用户设置；不把固定色散落到通用对象样式中。

所有下拉、配置、测试和右键控件均继承当前主题。Portal 渲染到 body 时需要传递触发区域的主题变量，避免菜单背景透明或文字与背景失配。ARGB 颜色使用统一选择器，不调用系统颜色弹窗。

### 复用可交互对象

字段和 Schema 共用 FieldCard 反馈；引用选择与只读派生结果复用成员控件。行小卡片复用 flow-palette-item；内嵌变量是其紧凑形态。画布变量默认复用普通节点移动，不另造一套坐标或连线更新机制。

仅 String、Number、Boolean 工作流参数允许直接编辑。Messages、Image、Tools 显示带类型提示的投放槽，接受引用或连线；不提供任意 JSON 编辑框。

## 交互反馈与拖动不变性

### 动画表达语义

悬停、按下、拖动、排序、展开收起和状态转换都应有连续反馈，而不是瞬间切换。动画用于说明焦点、归属与落点，不改变数据。减少动态效果偏好下保留状态辨识，停用复杂位移、旋转和长过渡。

成员 FieldCard 从中心轻微放大并通过阴影和主题色突出，不使用三维旋转，嵌套只突出当前最内层。工作流端口行只显示强调色细边框和浅发光，不突出、不缩放；内嵌变量保留突出和按下回弹反馈，悬停背景使用主题 hover 色渐变强调，区分值与参数容器。

### 形态由边界条件决定

对象正常拖动时保持其形态。树和列表使用跟随光标的同宽卡片和占位挤开相邻项；不因为进入拖动状态就缩窄或额外套蓝框。画布上的变量在普通移动时与其他卡片一致，位置及连线每帧同步，不留原位虚影。

节点库/变量池是行形态边界；其他节点是变量收缩边界；兼容参数槽是填入边界。变量进入这些区域才触发形态转换，拖离则恢复。节点库新建对象离开库后使用真实节点大小的空白矩形，强调色虚线边框和选中背景；只在暴露画布松开才能创建。

### 连续变形与比例

吸附由同一个拖动外壳改变位置、宽高和内容完成。目标槽预留最终内嵌引用空间，鼠标未松开时仍可拖走；不得以两份元素淡出/淡入代替填入。

预览在原始尺寸下布局，再整体缩放文字、图标、边距、边框和宽高。固定侧栏保持自身比例，画布与其内部引用使用画布比例。不能只改外框宽度；节点库空白预览尺寸由正式节点渲染器测量，避免另写内容造成差异。

### 手势与提交

移动阶段只产生预览和编辑工作状态，一次释放形成一次撤销事务。树/列表排序、端口绑定在有效落点松开时提交；取消、Esc、失焦与无效目标清理预览。层级移动禁止跨世界/分类及移入自身后代。工作流运行中禁用图与变量编辑，但允许观察和平移缩放。

## 界面会话与性能

滚动、选择、展开、缩放、搜索属于页面会话，不与世界持久内容混写。页面身份由对象 ID 构成，切页可恢复工作位置；异步回复和建议保持发起世界/会话身份。

平移、缩放、悬停、拖动预览尽量在局部交互层完成。关系网投影依赖 documents 快照建立索引与缓存，不随视角重算；节点拖动结束才提交布局。观察事件提供数据副本，不允许 UI 改写执行值。

## 设计状态与文档职责

当前设计说明最终行为和限制；实现缺口在所属章节明确标注。不能让“最后追加段落优先”成为规范解析规则，也不能以构建通过替代真实交互或模型服务验收。详细变更过程和历史验证只放 [修改日志](changelog/README.md)。

## UI 样式复用

同类控件显式组合 ui-surface、家族基础类与修饰类，公共皮肤只在基础 CSS 定义；页面只提供布局和必要覆盖。交互强度作为变体保留，危险、成功、警告使用主题语义色。具体分类与使用见 [UI 样式指南](ui-styles.md)。
