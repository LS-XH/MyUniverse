# MyUniverse 结构说明

## 项目目录

- `src/model`：世界、类、实例、属性结构和默认模板；Markdown 双向序列化与三方合并。
- `src/services`：浏览器预览与 Tauri 桌面版的数据保存接口。
- `src/ui`：创作、属性配置、关系网、地图和聊天界面。
- `src-tauri`：桌面程序及磁盘写入命令。
- `src-tauri/icons`：桌面程序静态图标。

## 数据保存

正式桌面程序将全部用户数据写入可执行文件同级的 `user` 文件夹。`workspace.json` 保存完整的可编辑状态；`worlds/<世界 ID>/` 同步写出每个类的 Markdown、属性结构 JSON，以及关系网、地图、聊天配置 JSON。程序不会向安装资源目录写入内容。开发模式的 `user` 文件夹位于启动命令的工作目录。

Markdown 使用一级标题表示类、二级标题表示实例，后续标题表示属性。Class 引用保存为 Markdown 链接。项目树与稳定 ID 由 `workspace.json` 保存，属性类型由 `.schema.json` 保存，实例内容启动时由 Markdown 还原。程序在重新获得焦点、定时检查和写入前重新读取 Markdown，并合并独立编辑；同一属性冲突时暂停保存并提示选择。文件操作页提供导入 MD 和实时源码分栏。格式、同步与错误处理详见 [Markdown 双向编辑](markdown-sync.md)。

设置内含蓝紫、暗黑与浅色预设，也可复制当前主题并调整各界面色彩。旧世界的人物关系属性会在加载时迁移为 `Class-关系`；旧文字值若恰好匹配已有关系实例名称，会转换为该实例引用。聊天记录保存在所属世界中，当前不会请求模型服务。

## 运行

1. `npm install`
2. `npm run dev`：浏览器预览，数据暂存于浏览器本地存储。
3. `npm run tauri dev`：开发桌面程序。
4. `npm run tauri build`：生成桌面安装包。

地图与聊天界面按规划只提供 UI 和配置入口，地图操作、模型接入与真正的多 Agent 工作流留有扩展位置，目前尚未接入。关系网、对象编辑和本地持久化可用。

## 界面交互

滚动条使用与主题一致的透明轨道和圆角滑块。Markdown 源码面板为右侧浮动窗，开关时滑入、滑出，不改变操作区的宽度；关系网详情也以覆盖面板显示。标题操作按钮带有悬停和按压反馈。项目树的根引导线仅覆盖实际项目内容。

关系网可通过 Shift 框选或点击、Ctrl 点击多选。松开修饰键后拖动任意选中卡片，会整体移动集合并保持相对位置。连线范围根据所有节点和预览光标计算，支持原固定画布范围外的节点与负坐标。`npm test` 同时检查多选位移与远距离连线边界。

设置的“模型”树列出全部连接配置，主页面可新增、编辑、停用和删除模型。配置包含显示名称、模型标识、接口地址和 API Key；访问密钥输入默认隐藏。连接配置保存在本地工作区元数据中，不写入人物等 Markdown。聊天输入框的模型菜单显示启用的模型，选择结果保存到当前世界的聊天配置。删除模型会清理各世界对该模型的选择。当前实现提供连接配置与模型选择，聊天消息仍保存到本地，模型请求与回复尚未接入。
