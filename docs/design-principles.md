# 界面与数据设计原则

更新日期：2026-10-09。本文解释历次修改的设计理由、当前规则及实现边界。需求总表见 [Planning](../Planning.md)，具体操作见 [界面与交互](ui-interactions.md)，模块职责见 [架构](architecture.md)。本文以最终确认的交互为准：右键显示对象菜单，收起箭头向右，Markdown 使用双栏，成员悬停轻微放大。

## 1. 页面、对象与数据的对应关系

世界是项目边界，集合负责组织对象，Class 定义实例结构，实例承载具体内容。文件操作页编辑实例，属性配置页编辑该 Class 的结构；关系网等视图读取同一批对象，不另建一套人物数据。

操作页应围绕用户正在处理的对象展开。点击世界进入该世界自己的集合列表；点击集合进入集合内容；点击文件进入实例列表。导航路径说明当前位置，树的展开状态只影响导航展示。

同一对象在文件编辑、关系网、函数调用与 Markdown 中应保持一致的身份。使用稳定 ID 定位对象，名称用于显示和编辑。改名不应使代码调用失去目标。卡片样式、排序、悬停和分栏都是展示行为，不改变对象类型或函数输入输出。

## 2. 内容驱动的居中布局

“充分利用空间”意味着允许内容按需要扩展，并保持整体居中。宽屏不应让每个输入框随窗口无限伸长。标题、内容面板和列表共享内容列：文件操作上限约 1180px，属性配置与关系配置约 1280px。

外层页面决定内容列宽度；内部控件根据内容和职责决定宽度。关系格式应尽量将实例 Key 和全部设置排在一行，列间距、标签行高、上下留白保持统一；可用空间不足时依照页面已有换行或滚动规则处理。

固定标题区与内容滚动区分开布局。实例列表的裁切边界紧接类名下方分隔线，首项间距放在列表内部，避免视觉上的边界与实际裁切边界不一致。属性配置和函数页同样不允许滚过的内容从固定标题上方露出。

## 3. 连续的导航树

### 3.1 层级表达

创建世界、我的项目和所有世界树共用一个滚动区域。减少功能分区、分隔线和底部提示造成的割裂。创建世界保持树行外观，通过字号、粗细和高度表明入口的重要性。

导航树继续使用层级引导线：线与父对象图标中心对齐，长度只覆盖实际子项，不伸到侧栏底部。导航树的引导线与成员编辑区是不同规则；成员编辑区改用嵌套卡片表达层级，不再绘制竖线。

### 3.2 打开页面与展开树分离

| 输入 | 结果 |
| --- | --- |
| 单击对象名称或主要区域 | 打开对象操作页，保留树展开状态 |
| 单击右侧箭头 | 只切换子树展开状态 |
| 双击对象主要区域 | 展开或收起子树 |
| 右键对象 | 打开对应页并显示该页操作菜单 |

展开使用 ChevronDown，收起使用 ChevronRight。箭头位于最右侧，按钮为 22px 方形，垂直居中并保留上下空隙。没有子项的叶子不提供展开按钮。上述规则用于世界、集合、文件与配置分支、插件文件夹、模型及主题集合。

### 3.3 页面动作只有一个来源

右键菜单复用页面真实工具栏动作及 SVG 图标，包括导入、添加、开关和删除确认，避免维护两套不同的行为。菜单沿用禁用状态，不绕过保护或确认。应用禁用 WebView 原生右键菜单，外部点击或 Esc 关闭对象菜单。

自建集合允许删除；只移除集合本身，直接子对象提升到上级，保留内容和引用。默认集合维持保护。删除世界、删除实例等具有不同数据范围，必须沿用各自动作的确认规则。

## 4. 成员卡片作为编辑单位

### 4.1 卡片边界对应键值对

文件操作中，一个成员卡片包含 Key、Value 和该成员绑定函数的结果。Object 的子成员递归成为内部卡片，归属通过包围关系、卡片边界和少量缩进表达。不能把函数结果误当成另一个可编辑原始成员。

文件操作的 object-body 移除左侧竖线与外侧缩进，保留约 6px 内侧间距。属性配置的 schema-children 同样移除竖线，保留约 8px 内侧间距。导航树的引导线不受这个调整影响。

属性配置复用同一个 FieldCard 外壳，但内部仍是类型、键、值类型、函数绑定、可重复性及删除等结构配置控件。整个 SchemaRow 保留排序身份，Object 的子结构继续在父行内递归展示。

### 4.2 向用户方向突出

悬停突出表示当前交互焦点。卡片保持原有排版位置，通过中心缩放产生向屏幕外靠近用户的感觉，不向上平移，也不挤动邻居。

| 项目 | 当前参数与规则 |
| --- | --- |
| 放大 | scale(1.008)，约增大 0.8% |
| 透视 | perspective(1000px) |
| 倾斜 | X、Y 轴分别最多约 1.6° |
| 中心位置 | 两轴旋转为 0，仅保持轻微放大 |
| 光标离中心越远 | 对应方向倾斜逐渐增加，限制最大角度 |
| 光标离开 | 旋转、缩放、背景、边框和阴影平滑恢复 |
| 嵌套成员 | 只激活最近的成员卡片，父卡片恢复，避免角度叠加 |

相对坐标换算到 [-1, 1]；横向坐标控制 rotateY，纵向坐标反向控制 rotateX，使卡片朝光标倾斜。进入时记录卡片边界，避免动画变换不断影响坐标测量。移动时只修改局部 CSS 变量，不更新实例、Schema 或函数任务，也不在每次移动时触发 React 状态重渲染。

变换过渡约 240ms，背景、边框和阴影约 280ms。背景与边框从现有主题色混合，保留暗色、浅色和自建主题的适配。触摸输入不启用光标倾斜；减少动画偏好下关闭变换与过渡。卡片装饰不截获输入、文本选择、删除按钮或引用菜单。

当前适用范围是文件操作的 entity-fields 和属性配置的 schema-editor-content。关系网详情复用字段编辑内容，但不因此自动获得整套成员卡片倾斜效果。

## 5. 控件宽度按内容和语义决定

对象引用选择器提供类名徽标、实例名称和下拉箭头，使用内容宽度，默认最小宽度约 200px，并受父容器约束。不能强制占满一行，把动态增加的附加控件挤到下一行。

“使用原值 / 引用函数返回值”是当前引用 Value 的来源参数。因此它与对象选择按钮在同一组内优先同行排列，间距约 8px，来源选择最小宽度约 130px；空间不足时才换行。选择结果仍走原有引用解析与函数逻辑，视觉布局不改变数据语义。

Text 短文本默认约 240px。隐藏的文本测量层使用相同字号、内边距和当前内容计算所需宽度，随着字符增加扩展，删除内容后可收回，最大不超过可用空间。超出页面可用宽度后由输入框承载文本，不继续撑破页面。Content 表示多行正文，保留宽幅编辑。只读函数结果中的短文本使用相同宽度规则。

输入控件可以紧凑，选择菜单仍需要足够的搜索与选项空间。对象选择和 # 建议菜单使用页面浮层，避免卡片、滚动区或倾斜变换造成裁切；按窗口边界决定向上或向下展开，并允许内部滚动。

## 6. 添加操作是完整按钮

添加属性、添加子属性和添加可重复成员使用完整的圆角命中区域，图标和文字都属于按钮。默认无边框、无突出底色；悬停使用主题 hover 背景和 accent 前景，按压使用 active 背景并轻微缩放。

背景、颜色和阴影约 220ms 过渡，按压变换约 180ms。键盘聚焦显示明确轮廓，减少动画偏好下取消过渡和变换。点击只执行原有添加逻辑，不把装饰动画纳入数据保存。

类名旁边的新建实例、标题操作区和导航展开按钮各自维持已有按钮样式；共享的是可见的交互反馈原则，而非强行使用相同尺寸。

## 7. Markdown 双栏与对象编辑共享数据

### 7.1 固定按钮与连续标题区

PanelRight 分页按钮始终固定在主界面右上角，展开或关闭源码列时不左右滑动。源码标题区延伸至主界面顶栏顶部，包含文件名、保存状态和分页按钮，与下方源码列在宽度和背景上对齐。

当前由 DocumentWorkspace 将标题区放入主顶栏，避免重复按钮。源码列和标题区展开宽度约为 clamp(280px, 34%, 420px)，宽度过渡约 280ms，透明度过渡约 220ms。标题区可以扩展，按钮的右侧位置保持固定。

Markdown 是独立的第二列，开启时给它分配空间并收窄操作列留白，关闭后恢复。它不覆盖实例卡片。左侧字段编辑或空白点击保持双栏打开，顶部按钮或 Esc 关闭，页面会话记住开关状态。

### 7.2 对象与源码互为可编辑表示

左侧修改对象、右侧修改 Markdown 都进入同一解析与保存流程。左侧选中实例名、键或值时定位对应源码行，使用主题 markdownHighlight 显示透明浅绿色背景。右侧 # 标题按层级放大加粗，但仍保留可编辑源码；代码围栏内的 # 不当成标题。

合法源码解析为对象再保存；非法源码保留草稿和最后有效对象并显示错误。桌面外部文件变化通过焦点、可见性、定时检查和写入前读取发现，三方合并处理独立修改，冲突时保留明确选择。JSON 提供结构、身份与缓存，不能取代对 Markdown 实例内容的读取。详细格式及冲突行为见 [Markdown 双向编辑](markdown-sync.md)。

## 8. 页面会话保留工作位置

页面按世界、对象与配置身份保存运行期间的浏览状态。切换页面不意味着重置实例展开项、列表滚动、双栏状态、关系网视角和倍率、选择与详情、Flow 画布位置或聊天草稿。

关系网“在人物列表中打开”是带目标的导航：展开目标实例，滚动到可见位置并高亮约 4 秒。普通页面切换则恢复原浏览位置。会话缓存不写入 Markdown 或工作区 JSON，重启后重置；卸载时释放拖动监听，避免保留过期数据引用。

## 9. Function 的类型与呈现一致

Function 用项目类型规范输入和输出。新接口 transform(self, input) 中，self 是调用实例，input 是当前绑定 Value 的类型对象；返回声明独立于绑定属性的类型。绑定到 Object 不代表函数一定返回 Object，函数自身返回规范也必须匹配。

脚本与 Flow 共用对象访问和执行协议。代码保持自由表达能力，对象助手通过选择类、实例与逐级成员插入稳定 ID 调用，Flow 通过文件操作卡片封装同一接口。用户不必记忆全部对象路径，也不被固定卡片集合限制表达能力。

成功结果按 typedValue 渲染：Object 递归成员，Text/数字/日期只读输入，Content 只读多行输入，Class 值及引用键使用禁用选择按钮。只读控件显示完整值并允许复制文本，但不提供编辑、增删或展开选择菜单。错误与等待分别展示；原始 Value 仍保留。

Markdown 保存可逆类型元数据及结果正文，读取时恢复类型而非从展示文字猜测。执行错误展示实际 JS 堆栈、Python Traceback、进程退出码或环境启动错误；桌面 JS 使用 runner.cjs 避免上级 type: module 使 require 失效。完整接口与兼容规则见 [Function](functions.md)。

## 10. 关系网以对象操作为中心

空白拖动与空白点击通过移动阈值区分，拖动视角不清除选择。连线是可开关模式，可预先选起点或依次选两个对象；空白仍可拖动画布，Esc 退出，已选起点后显示到光标的透明预览线。

多选人物可整体拖动，详情显示共同属性与混合值并允许批量设置。拖动中仍可缩放；缩放围绕光标，倍率范围 8%–300%。边缘平移提前在内部区域触发，距离边缘越近速度越快，根据整组卡片边界计算。画布范围由节点和预览端点动态决定。

关系箭头表达起点人物到目标人物的方向。线条填充、外围边框、填充发光分别渲染，箭头使用一致的颜色和粗细，线段终点缩短以避免与箭头重叠。悬停增强当前格式的填充亮度与光晕，保留其线型、线宽和配色，约 240ms 渐入渐出。关系文字显示开关属于视图配置。

## 11. 主题、动画和交付边界

主题提供蓝紫、暗黑、浅色预设及自建主题；共用语义颜色使卡片、按钮、引用、源码高亮和画布协调变化。颜色菜单提供 ARGB 和透明度，八列色系、每列八级深浅的方形预设，选择预设保留当前透明度。

动画表达焦点、导航和操作反馈。它不改变数据身份、排序结果或引用含义；减少动画偏好必须可用。主题功能目前使用共享语义色项，不等同于逐个 DOM 元素独立配色。

代码修改后按约定自动打包，复用 my-universe.exe 名称并更新根目录快捷方式。运行中的程序锁定文件时，保留 target-next 中的编译结果并如实说明未覆盖；不自动强制终止应用，也不宣称快捷方式或正式程序已更新。仅更新文档时无需重新编译程序。

## 12. 维护与验收

- UI 改动同时维护 Planning 的需求约束、本篇的设计理由及 ui-interactions 的具体操作。
- 数据或函数协议改动同步维护 markdown-sync、functions 与 architecture。
- 追加需求发生覆盖时修正旧描述，避免浮动/双栏、左/右箭头、左键/右键菜单等相互矛盾。
- 保留原始规划副本作为历史材料，不把它当成现行交互规范。
- 区分已实现、编译验证与实际界面验收；当前卡片动画已通过构建，本文不将构建结果表述为所有平台的视觉验收。
- 真实地图交互及双实线等未完成能力，继续按各专项文档记录边界，不因界面调整标记为完成。

## 模型与 Agent：能力节点与显式状态

模型是独立功能入口。LLM 节点负责输入到输出，不自行记忆；上下文作为可见的数据经过独立节点和变量保存，便于控制历史长度、顺序和重置。Agent 变量按世界隔离，执行失败不提交本次变量变更；外部服务已经产生的效果无法回滚。SD 将世界对象/Function 的求值与 ComfyUI 原生计算区分，保持原生节点连接语义。共用画布用于节点编排，脚本自由度通过已有 Function 提供。详见 [模型与智能体](models-and-agents.md)。

## 编辑工作区优先（2026-10-09）

文件夹/集合列表使用完整 page-heading 与 heading-actions 展示集合名称及新建入口。进入具体绘画工作流、Agent 或 Function 后，不再重复占据大块空间的标题、说明和创建按钮。顶部使用 48px 紧凑工具栏标识当前对象，导入/导出等操作为辅助；主区域无居中宽度限制和外围留白，画布或源码编辑器填满剩余高度与宽度。

配置、初始变量、接口规范及测试输入/结果通过“配置”和“运行/测试”打开右侧覆盖面板，默认关闭，不挤压画布。两个面板互斥，运行结果/异常可查看；辅助面板可独立滚动。对象调用助手和节点库保留在编辑区边侧。文件夹列表保留新建功能，具体编辑页提供精简动作，右键菜单继续复用当前真实工具栏。

这个规则强调当前任务的主操作载体：用户进入工作流是为了编排节点，进入函数是为了写代码，标题和说明应让位给这些操作；无需将所有页面统一套用列表页的标题布局。

## 统一顶栏与画布工具栏（2026-10-09）

所有画布区域禁止选择卡片标题、说明、标签和地图文字，防止拖动/框选时出现文字选区；输入框、文本域和可编辑内容仍可正常选中文本。模型侧栏根文件夹采用与插件相同的 13px/600，子项 12px/400，避免名称旁有计数时被 CSS last-child 规则漏掉。

页面 heading-actions 的动作在主界面顶栏显示为带图标、悬停提示的按钮，位置在固定 Markdown 分页按钮左侧。打开 Markdown 时，该动作组随源码列宽度渐变向左移动，分页按钮仍固定最右。非文件夹页隐藏原 heading-actions；文件夹页保留原按钮组，同时提供顶栏入口。顶栏调用原按钮，复用禁用、开关、导入和确认行为，避免产生两套操作实现。

绘画、Agent 与 Function Flow 只保留一条画布工具栏：配置、运行/测试、适应画布与删除所选在这条栏中。导入、导出、删除文件等页面级操作移到主界面顶栏。脚本编辑器保留紧凑配置/测试栏。右键菜单继续读取真实页面操作，包括新画布工具栏。

### 文件搜索与右键行为（2026-10-09）

文件页标题行在类名和加号右侧提供居中的搜索框，按实例名称实时过滤，支持清空，搜索状态随页面保留；关系网定位具体人物时清空搜索，以保证目标可见。顶栏动作图标统一为 20px，与 Markdown 分页图标一致。

右键不调用树行的 click，不改变当前世界、页面、主题或选中对象；只记录菜单目标与可用动作。菜单提供打开与目标的操作项。仅当用户选择菜单命令时打开目标页面并调用真实操作按钮，保留删除确认与禁用检查。关闭菜单无需恢复页面，因为没有发生导航。

### 搜索栏居中与无结果状态修正（2026-10-09）

搜索栏与类名 h1 位于同一个无 class 的父 div，使用左右等宽轨道使其水平中心与整个标题框中心一致，并在同一行纵向对齐，不以类名右侧剩余空间为参照。标准宽度由 320px 增至 640px；编辑区较窄时换到单独一行，仍相对标题框居中。浏览器实测标题框与搜索栏中心均为 x=640，搜索宽度为 640px。

搜索无结果不使用 empty-card：采用无外框的轻量搜索图标、结果说明与可清空按钮，颜色跟随主题，出现时轻微渐入。初次未创建实例的引导与搜索无匹配状态分别呈现。

## 变量是对象，状态保存必须显式（2026-10-09）

变量声明必须有具体类型；方法与属性属于该类型，不能依靠 ANY 和任意 JSON 猜测语义。读写合并，因为一个变量天然能接收新值并输出当前值；方法负责计算，变量节点负责存储。模型调用不隐藏历史，Messages 显式管理角色、工具调用配对和完整轮次；Image 保存资源身份。界面应直接体现这些对象能力，节点库使用类型子文件夹，交互与其余画布共享。详细契约见 [workflow-types.md](workflow-types.md)。


## 工作流运行观察与变量池（2026-10-09）

执行状态独立于持久化图定义：节点依次发出 waiting、running、complete，异常标记 error，取消标记 cancelled。运行面板将当前执行节点高亮；每条实际经过的连线记录本次输出及实际类型，显示紧凑摘要，悬停查看完整值。观察事件使用副本，不能改变程序数据。编辑器播放在节点开始时短暂停留，普通调用不附加展示延迟。

变量池维护 `{id,type,value}` 类型信封。id 是稳定身份，name 是可编辑的索引；节点通过下拉列表选择兼容类型的变量。新建、改名、改类型、初始值编辑和绑定节点修改纳入同一撤销快照。改名同步节点绑定以及各世界的 Agent memory；改类型同步 value 端口，兼容值保留，不兼容值恢复类型默认值。连接保留，运行校验提示不兼容类型。旧的原生值可以推断基础类型，无法推断的对象需明确指定类型。

运行使用工作副本，变量池实时显示变量写入结果；成功后提交 Agent 记忆，失败或取消不提交临时值。变量池显示最近运行值时，初始值编辑仍明确标注，避免混淆。运行中禁用图定义与变量编辑，保留平移、缩放、查看完整值及面板开关。

ComfyUI 原生节点的执行通过 WebSocket 按 prompt_id 过滤，桌面端使用原生连接并通过 Tauri 事件桥接，支持 Bearer 认证。浏览器使用 WebSocket。原生 ComfyUI 公开事件不包含所有 Tensor 的实际值，因此对应连线显示“服务端数据 · 类型”；不会编造 Tensor 数值。宿主节点的值正常展示。事件通道不可用时提示并继续 HTTP history 查询。真实模型与 GPU 联调仍需要实际服务。

节点库与变量池都采用固定 header 加独立滚动内容区。节点库标题、收起按钮和工具栏保持顶边对齐，滚动只作用于搜索与分类列表；此结构同步用于 Function Flow。变量池位于画布右下方，可用分页按钮滑动收起。

最新图标规范覆盖早期方案：模型入口 Sparkles，插件 Puzzle；LLM 使用与模型项一致的 Bot，SD 项及节点使用 SquareSparkles，工具独立分类 Wrench；String 为 Letters，Boolean 为 Binary，其他变量类型 ScanBox，方法 FileCodeCorner，属性 FileBox。缺少的 Lucide 图标使用本地官方 SVG 与 ISC 授权，无运行时下载。


## 界面操作类型的对象投影（2026-10-09）

采用 `World.views[id]: InterfaceView`，每个视图必选父 ClassDocument，显示元素由稳定 ID 路径绑定，支持当前实例与固定对象、Markdown 序列化文本与内容值。关系网和地图共享绑定解析器；源对象编辑写回原 Markdown，布局独立保存到 `<view-id>.view.json`。集合层级是 JSON 虚拟组织，所有文件继续平铺在原 world 目录，另输出 world-index.json 组织清单；旧项目自动补默认绑定，不移动文件。视图配置纳入读取、三方合并与写前竞态检查。详细结构、上下文和兼容边界见 [界面操作类型与数据结构](interface-views.md)。
