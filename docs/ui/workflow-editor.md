# 工作流编辑器设计

适用 Agent/SD 的 WorkflowEditor 与 Function 的 FlowEditor。共用编辑手势，图数据和执行契约保持各自定义。类型逻辑见 [工作流类型](../data/workflow.md)，模型逻辑见 [模型与 Agent](../features/models-and-agents.md)。

## 工作区结构

编辑器填满主区，顶部为紧凑 flow-toolbar，标识工作流类型与文件名；右侧排列配置、运行/测试、适配视图和图编辑动作。节点库位于工具栏下方，滑入滑出并保留页面状态，关闭后禁止交互。Agent/SD 宽度由辅助停靠区统一决定；Function Flow 使用自身库侧栏。

Agent/SD 的 workflow-library-panel 同时包含节点库和变量池。变量池在底部通过高度动画展开，挤占节点树空间；展开按钮移到池右上角，不是浮窗盖在按钮上方。Function Flow 无 Agent 记忆池。

配置、运行与节点库共用右侧停靠区，互斥显示并参与布局，画布让出宽度；标题固定、内容独立滚动。关闭辅助面板恢复原节点库开关，点击画布不关闭停靠区，避免画布反复改变宽度。

## 工作流辅助停靠区

Agent/SD 的配置、运行与节点库在同一右侧区域互斥显示，从 flow-toolbar 下边开始，到画布底部结束。区域参加布局，画布让出约 340px（不超过编辑区 45%），使用共享 ui-drawer--dock 的主题底色和左分隔线，无悬浮阴影与圆角。面板标题固定，内容独立滚动。点击节点库切回节点库，关闭配置/运行恢复原节点库开关；点击画布不自动关掉停靠面板，避免编辑时画布宽度反复变化。草稿输入和库的搜索/展开状态不因视图切换丢失。运行执行方式、取消和结果保持原契约。Function/Tool 源码配置浮层保持独立。

停靠区使用一个固定宽度的槽；面板开合与互换只使用 280ms transform 滑动和 220ms 淡入淡出，不动画 width/flex-basis。首次打开让出槽宽，全部关闭后等待滑出结束再释放宽度，配置/运行内容切换使用 200ms 轻微过渡。关闭时保留壳与上一份内容直到滑出，关闭视图 inert 且 aria-hidden；减少动态效果下立即切换。运行内容用共享 ui-panel--plain，无重复卡片外框。

## 节点库

标题旁提供展开/收起全部目录，递归作用于类型、基础变量、方法、属性及 ComfyUI 分类；单目录仍可独立展开。Agent/SD 搜索固定在标题下、不在树滚动区，与下方留间距。Function Flow 复用目录控制和无线条样式，当前没有同样的搜索输入。

Agent 增加“流程控制”目录（循环、条件）和“Agent”调用目录；变量类型包含独立 Agents。循环/条件在卡片内选择 T，循环还可修改最大轮次。输入节点可选择 Schema 字段，Agent 配置编辑启用、调用说明、JSON Schema 和预算。

目录按功能和变量类型分组，类型目录包含基础变量、方法、属性；没有成员的子目录仍保留组织规则。移除全部层级线，保留缩进和箭头。变量类型文件夹使用该类型图标，而非统一 Folder。

悬停节点时右侧对齐、渐显输入类型图标 → 输出类型图标，顺序按端口定义。节点标题属于类型固定属性，变量名、模型选择、Tool 选择在卡片内部显示；旧序列化 title 不用于改名。

### 图标语义

| 对象 | 图标 |
| --- | --- |
| String / Number / Boolean | Letters / Hash / Binary |
| Messages / Image / Tools / Agents | messages-circle 双圆消息 / Image / Wrench / Network |
| 循环 / 条件 | Repeat / GitBranch |
| 类型方法 / 属性 | FileCodeCorner / FileBox |
| LLM / SD / ToolCalls、调用 Tool | Bot / SquareSparkles / Wrench |
| 输入、返回 / 世界、Function / 运算、常量 | ArrowDownUp / Database / Sigma |

文件夹使用所属类型的图标；未知类型保留 ScanBox 等后备，不把所有变量改为同一图标。缺少的 Lucide 组件以本地官方路径生成内联 SVG，固定尺寸、不收缩、currentColor 描边；不使用带背景 span/mask，不在运行时下载。授权保留在资源目录。

### 从库创建节点

点击列表不添加；必须拖出节点库并在暴露画布松开。落点在库、停靠区或其他浮层时不能在背后的画布创建。

库内预览复用 flow-palette-item 行样式。离开库动画变为目标尺寸的空白矩形，只有主题 accent 虚线边框和 active 背景，不填入节点内容。由正式 renderNode 在隐藏容器测量宽高，Agent/SD 与 Function Flow 使用各自真实渲染器；不能按端口数估算高度。返回库恢复行形态，取消不创建。

## 变量池

标题右侧依次是新建、清空全部值、收起图标；每项可改名、选择明确类型、修改初始值、清空或删除。类型菜单背景/文字来自主题，通过 portalTheme 保持继承。名称不是稳定身份，排序使用 graph.variableOrder 中的 ID。

变量可拖到画布、兼容端口或在池内上下排序，邻项通过动画挤位显示落点；释放保存顺序，取消不改图。变量池标题固定、内容独立滚动。删除、清空、改名、改类型及世界记忆同步规则由 [变量池的数据职责](../data/workflow.md#变量池与稳定身份) 维护。

初始值和本次运行值明确区分。运行中禁止编辑图及变量定义，允许查看实际值、开关面板、平移和缩放。实时写入值不等于成功提交的记忆。

## 卡片与端口

### 固定标题与正常移动

卡片标题是类型名称；“读取历史”等用途不作为独立可改标题。变量读写均显示“类型 变量”，成员显示“类型 · 成员名称”。普通画布变量和其他卡片共用 useCanvasEditing 的选择、坐标更新、端口测量、连线重绘与撤销事务。

正常拖变量时完整卡片与连线一起移动，不隐藏原位留下虚影，不使用另一个 DOM transform 假装移动。边界转换仅为普通移动增加回调。

普通画布移动始终显示正式节点本体，保留原生控件当前值、选中边框和内部布局；此阶段不生成节点克隆。边界预览整体隐藏时必须阻止所有子元素显现，不能仅依赖可被后代覆盖的 visibility。进入边界后需要克隆时同步 input、textarea、select 的运行时状态，不能把 HTML 属性当作当前值。

### 输入、输出、输入输出

每行显示类型图标。按操作语义合并相同输入/输出，保留两端端口；不能仅因类型相同就合并。例如 Messages.user 的 self/value 可配对，Messages.count 输出 Number，必须分行。

基础 LLM 的完整上下文与响应 Messages、ToolCalls 的请求上下文与工具结果、Tools.get 及 Image.fromUrl/fromSD 的输入主体与新建结果必须分行。每张 Agent/SD 和 Function Flow 卡片在标题下展示固定注释，说明输入、输出、保存或副作用及主要限制；注释来自节点类型定义，不是用户节点命名。成员节点说明其操作行为，不因类型相同而暗示自动合并或保存。

行左右留白、上下有间距；flow-connected-value 保持紧凑宽度。所有 flow-input-row、flow-output-row 和 flow-input-output-row 悬停显示细强调色边框与浅发光，不放大、不突出。只有行内的可交互变量使用突出反馈。

仅 String、Number、Boolean 显示直接编辑控件；Messages、Image、Tools 等显示引导“拖入变量卡片”的类型槽，亦可连线。已有连线显示只读来源。非基础值不开放原始 JSON 文本编辑。

### 内嵌引用

变量可以拖到输入标签/槽成为 flow-inline-variable。独立输入读取变量，独立输出写变量，合并行先读后写。引用两侧端口继续可连线；有线输入先同步变量，输出同步变量后继续分发。断线保留引用、解绑保留线，拖动与撤销保持稳定 ID。完整数据规则见 [端口绑定](../data/workflow.md#端口变量引用)。

内嵌变量为 flow-palette-item 的紧凑版本，无边框，静止时背景透明；悬停使用主题 hover 背景色渐变强调，并保留突出、点击回弹反馈，提示可拖动。点击引用本体不解除绑定，只有解除按钮执行移除。可拖出移除绑定并恢复对应类型变量卡片，变量池定义保留。

## 拖动形态与吸附

| 条件 | 显示 | 松开结果 |
| --- | --- | --- |
| 变量在普通画布移动 | 正式完整卡片，连线跟随 | 移动节点 |
| 节点库/变量池内 | 行卡片 | 保留库项或变量池排序 |
| 库项离开列表到暴露画布 | 真实卡片尺寸的空白矩形 | 创建节点 |
| 变量进入其他卡片 | 保持完整卡片 | 未落兼容槽不绑定 |
| 变量进入类型兼容槽 | 外壳向目标变形填入 | 建立引用 |

变量只有进入兼容 inline-value 槽时才暂停普通移动，从完整卡片直接变形填入；进入父卡片其他区域仍保持完整卡片并正常移动。节点库/变量池内仍使用行卡片，列表形态不作为吸附的中间步骤。变量池来源离开后成为完整变量预览，节点库新建对象则使用空白矩形，两者职责不同。

吸附不是把光标的对象位置突然移到槽，也不是两份对象交替淡入淡出。目标先预留临时内嵌引用的最终布局空间，同一个 DragCardPreview 外壳改变位置、宽高、颜色和内容，连续变成内嵌变量；释放后正式引用接续。鼠标未松开仍可拖离撤销临时填入。预览不改真实绑定、连线、变量值或记忆。

从已有内嵌引用拖出时逆向复用同一外壳：在原槽建立隐藏预览、记录抓取点，超过拖动阈值后才隐藏原引用的视觉内容并显现预览；原槽保留布局，不显示模糊残影。光标离开原兼容槽后直接展开完整变量卡片，即使仍在父卡片内也不经过行卡片；回到兼容槽可直接再次填入。形态切换时位置与尺寸连续过渡，普通移动保持跟随光标。松开且落点有效才提交解除/绑定/新建事务；取消或无效落点恢复原引用，一次有效拖动只记一次撤销。

完整变量预览以自身左上角为坐标原点，预览节点 ID 在同一次拖动内保持稳定；不能带入画布节点的 left/top，使内部内容再次向右下偏移。源节点克隆同样清除画布位置，正式节点仍采用世界坐标。

所有预览先在世界原尺寸布局，再整体 transform scale：宽高、文字、图标、内边距和边框同步缩放。画布及父卡片内预览用画布比例，固定侧栏用自身比例；不只缩宽导致换行和高度失真，不重复缩放。

## 选择、连线与编辑命令

| 操作 | 行为 |
| --- | --- |
| 空白单击 / 拖动 | 清选择及待连线 / 平移并保留选择，按位移阈值区分 |
| Shift 空白拖动 | 框选相交卡片；Ctrl+Shift 追加 |
| Ctrl 点击、拖已选卡片标题 | 多选切换、整组选中节点移动 |
| 滚轮、适应画布 | 光标中心缩放、查看全图 |
| 点击端口或拖线 | 可从输入/输出开始，提交规范为输出 → 输入 |
| 双击输入、Esc | 断开输入连接、取消连接 |
| Ctrl+C/V/X、Del | 复制/粘贴/剪切、删除选中节点或连线 |
| Ctrl+Z/Y | 撤销/重做，最多 100 个图快照 |
| Tab | 展开/收起节点库 |

文本与代码编辑获得焦点时快捷键保留文字语义，Tab 不劫持输入。复制只保留选中节点内部的线，重建节点/线 ID，粘贴每次偏移 36 世界单位；变量名保留，复制变量卡片仍访问原变量。剪贴板带 myUniverseGraphClipboard 标记，Agent/SD 与 Function Flow 不混粘图 Schema。

原生下拉菜单展开时保留菜单操作；提交选项后结束菜单编辑，把焦点交还画布，使删除、复制、粘贴与撤销继续作用于工作流。点击空白画布或拖动节点标题同样交还焦点；点击输入框、多行文本和可编辑内容保留文本焦点。此规则由 Agent/SD 和 Function Flow 共用的画布手势实现，不能依靠点击工具栏恢复快捷键。

一次完整拖动只记一个撤销步骤。删除节点同时删除关联线；撤销只恢复编辑定义，不能撤回网络、图片或已提交 Agent 记忆。图执行须满足入口/返回和合法循环边界，禁止未经循环卡片管理的环。

卡片与空白支持同一右键菜单，复用顶部复制、粘贴、剪切、撤销、重做、删除、适配、节点库、配置、运行动作。空白时复制/剪切/删除灰色禁用，运行中编辑动作禁用。

## 执行观察

观察状态独立于持久图：waiting/running/complete/error/cancelled。实际经过的边显示值和类型摘要，可查看完整值；变量池显示运行副本。观察事件克隆数据，不允许编辑器改写执行值。轨迹以调用实例、循环 frame 和节点区分；子调用不覆盖根变量池。循环进度、分支选择和嵌套调用身份同时送往聊天。

ComfyUI 原生 Tensor 值未公开时显示“服务端数据 · 类型”，不编造值；事件通道失败继续 history 查询。显示延迟只用于编辑器观察，不加入一般程序调用。

## 画布性能

视角平移与缩放只更新 stage transform，不应重建 ComfyUI 节点库或逐个测量全部端口。节点库按 catalog、查询和展开状态缓存，节点控件按图/选择/运行状态缓存。端口坐标在 stage 本地坐标系计算；图或节点尺寸改变时通过 requestAnimationFrame 合并测量，坐标未改变不更新状态。

普通节点拖动使用本地预览，松开时一次提交，并作为一次撤销事务；取消丢弃预览，不保存或增加撤销项。变量卡片的跨区域拖放继续交给变量绑定逻辑。参数与连接编辑继续走原保存路径。

## 代码入口与边界

WorkflowEditor/FlowEditor：主结构与正式节点渲染；WorkflowPorts：行配对与引用；VariablePool：池控件；useCanvasEditing/useGraphEditing：手势与历史；useVariableDrag：边界；DragCardPreview/useDragCardSize：同一外壳及测量；libraryDrop：暴露画布校验；WorkflowIcon：图标。

Function Flow 使用独立 void/add 契约；结束节点仅驱动依赖求值，不把最终计算值写入世界，详见 [Function](../features/functions.md)。它有自己的输入与代码块端口，复用选择、右键、库拖出动画、端口悬停及图标，不承诺 Agent 的七型变量池和世界记忆。真实缩放、连线跟随和落点验收见 [开发与验证](../development.md)。
