当作品越来越长，真正难管理的往往是散落在各处的设定：谁与谁有什么关系？某个势力活动在哪里？一次事件影响了哪些人物？AI 给出的新内容，又该如何纳入原有世界？

MyUniverse 将这些信息组织成可编辑、可引用的世界对象，再用人物关系网、关系类型网、地图和 AI 工作流帮助你查看、补充和使用它们。你可以从一张人物卡片开始，逐步建立属于自己的完整宇宙。

> **写得清楚，看得直观，扩展得有章法。** 全部对象自动存档至 JSON，Markdown 用于导入与导出；AI 可以查询世界、提出建议，由你决定哪些内容成为正式设定。

## 为什么选择 MyUniverse

| 创作中的需求 | MyUniverse 带来的帮助 |
| --- | --- |
| 设定分散，查找困难 | 按世界、集合、类别与实例组织，结合名称搜索和递归属性筛选定位内容 |
| 人物关系复杂，文字列表难以理解 | 用有方向的关系网展示每一条关系，双击人物聚焦其直接关联对象 |
| 同一对人物具有多重身份 | 多条关系分别连线，用曲线区分同向、双向连接 |
| 不同设定需要不同填写方式 | 自定义属性类型、重复项和多层子对象，用同一套结构约束实例 |
| 希望 AI 使用已有设定协助创作 | 接入查询工具，让模型读取所需对象；新增与修改建议可查看差异后采纳 |
| 重复处理步骤耗时 | 用 Agent 图、Function 和自定义 Tool 编排可复用流程 |
| 希望保留可读的创作资料 | 桌面版保存 Markdown 正文、JSON 配置及函数脚本，便于查看与备份 |

## 世界与项目管理

**一部作品，一个清晰的创作空间。** 每个世界拥有自己的对象、视图和聊天会话，适合同时维护不同小说、剧本或游戏设定。

新世界提供人物、关系、势力、地点和事件的基础结构，以及章节、插图的组织集合。你可以继续创建子集合和自定义类别，例如装备、种族、能力或任务，按作品需要扩展资料体系。

- **层级组织**：用集合和子集合整理类文档，展开导航树即可访问具体对象与配置。
- **拖动整理**：调整世界顺序，将文件移动到同世界的集合中；组织调整保持对象身份和引用。
- **多视图管理**：在源文件下创建视图，视图与配置以并列入口展示。可以为同一类数据保存不同布局和样式。
- **独立展示配置**：创建视图只改变项目组织与 JSON 配置，不向 Markdown 正文插入界面信息。
- **存档与导出提示**：JSON 自动保存状态单独显示，文件和实例标记尚未导出的变化。

## 结构化设定与对象编辑

### 自定义你的设定模板

先定义一类对象需要哪些属性，再按结构创建实例。人物可以有性格、喜好、所属势力与关系故事；物品可以有价格、持有者和效果；事件可以引用参与人物并记录结果。

| 属性能力 | 可以如何使用 |
| --- | --- |
| 短文本与长正文 | 填写名称说明、人物特征、背景故事和完整描述 |
| 整数、小数与日期 | 记录数量、数值与日期信息 |
| 类实例引用 | 选择已存在的人物、地点或其他对象，建立明确联系 |
| 嵌套对象 | 将一个复杂属性拆成多层子成员，例如活动的地点、频率与内容 |
| 可重复成员 | 为同一对象填写多条关系、多段故事或多个参与者 |
| 固定、文本或引用 Key | 根据需要使用固定属性名、自由条目名或对象作为键 |
| 无内容成员 | 用只含 Key 的条目表达对象列表或关系类型 |

属性配置还支持提示文本、成员排序和函数绑定。结构与实例内容均自动保存到完整 JSON；Markdown 的更新由你通过保存键明确导出。

### 更顺手地维护大量实例

实例以可展开卡片展示，名称直接编辑，成员按对象层级组织。长正文支持自动换行与高度适配，减少在小输入框中反复滚动。

支持单选、多选、框选、复制、剪切、粘贴、删除、撤销和重做。实例可以拖动排序，也可以批量添加或清除颜色标签。例如，用不同颜色区分主角、配角和待完善档案；标签与颜色保存在 JSON 中，不混入正文。

文本中输入 `#` 可搜索并插入世界对象引用；引用类型属性也有专用对象选择器。把地点、人物和事件连接起来后，设定便能作为后续视图与工具调用的数据来源。

## 搜索与属性筛选

**从整份档案中，只看这次需要的内容。** 名称搜索快速定位实例，搜索栏右侧的筛选按钮则提供递归属性检索。

筛选浮窗包含两个选项搜索框，以及 `Key = Value` 两个下拉菜单：

1. 选择“当前类实例”或实例中实际存在的任意层级 Key。
2. Value 菜单列出该 Key 的已有值；不选择 Value，表示展示拥有该 Key 的全部匹配内容。
3. 卡片只保留匹配成员、通往它的祖先路径及匹配对象的子树，隐藏无关旁支。

例如，在你已配置的物品类中选择 `颜色 = 蓝色`，可以集中查看蓝色成员所在的分支；在人物类中选择 `人物性格 = 谨慎`，可以与名称搜索结合缩小范围。多个匹配分支会同时保留。

筛选只改变显示。隐藏内容仍保留在原始对象中，编辑可见成员不会丢失其他旁支；清除条件即可恢复完整卡片。函数生成成员另有显示开关，方便专注于手写设定。

## Markdown 与保存管理

### 对象编辑与可读预览

全部对象以 JSON 为唯一数据源，保留实例身份、引用、函数来源和视图信息。打开右侧 Markdown 双栏，可查看后台生成的只读导出预览；选择实例、属性键或值，可定位对应正文位置。

预览展示相较初始或最近导出版本的行差异，公共内容保持原位置，局部增加和修改分别标记。关闭预览时不生成全文，避免影响对象编辑。

### 自动存档，按需交换 Markdown

- **JSON 自动存档**：编辑内容、结构、视图、模型或聊天后自动保存完整工作区，状态提示写入进度与失败。
- **保存当前文件 / 保存全部**：明确导出对应 Markdown、JSON 配置和脚本，方便阅读与交换。
- **刷新 / 导入 MD**：读取 Markdown 并按当前属性结构导入，逐实例更新；无效文件不会作为有效对象写入。
- **重新计算函数**：独立计算当前类绑定，不先导入 Markdown；后台执行并逐实例提交。
- **停止任务**：可以停止导入或计算，保留已完成实例；计算过程中界面仍可操作。

桌面数据保存在程序同目录的 `user` 文件夹。`workspace.json` 保存完整对象，Markdown 是导出产物；首次升级 JSON 存储模式时保留旧存档备份。建议定期备份整个 `user` 目录。

> 外部修改 Markdown 不会影响应用启动加载；需要使用刷新或导入明确更新 JSON。导出会写入当前内容，不自动合并外部文件。

## 人物关系网

**让人物联系成为可以探索的画布。** 人物卡片展示姓名与势力信息，箭头表示关系方向，势力背景辅助理解阵营分布。

### 多重关系清晰呈现

同一对人物可以同时存在多条关系，每个重复关系值分别绘制一条线。双向连接和同向多线使用曲线避让，自引用使用环线，方便分别查看关系名称与方向。

连线样式按关系类型设置，支持颜色、透明度、边框、线宽、线型、发光与文字大小；可以控制某种关系的可见性，也可切换关系文字和函数生成关系的显示。势力背景支持颜色、边框及不同图案。

### 在画布上继续完善设定

支持平移、围绕光标缩放、多选、框选和整组拖动。选择人物查看详情，新增卡片创建人物实例，新增连线写入起点人物的关系成员。每条关系可以独立编辑或删除，保留同组其他关系与关系故事；修改进入同一份源数据。

双击人物进入个人关系网，将其直接关联人物围绕中心排列，集中查看入向与出向联系。退出后恢复完整网络的视角；个人聚焦布局与完整关系网布局分别管理。

## 关系类型网

**除了人物之间的联系，也能梳理“关系”本身。** 关系类型网读取“关系类型”类别，每个实例是一张卡片，名称为标题，关系描述为副标题。

当前关系实例作为连线起点，“关系推理”子对象中每个成员的 Key 决定连线内容，Value 决定终点卡片。你可以用这套结构记录自己的关系规则或推理链，再在画布上查看连接。

关系类型网复用平移、缩放、多选、拖动、详情编辑与双击聚焦，并用曲线区分同端点多线。新增节点与连线会编辑关系类的对应实例与推理成员。

**样式可以复用。** 在关系类型网配置中选择同世界的人物关系网，导入关系连线格式与相关显示开关；卡片位置和视图身份保持独立，导入后两份配置可分别调整。

> 关系类型网展示已填写的推理连接；自动推导新关系需要自行设计 Function、Tool 或 Agent 流程。

## 地图视图

**把地点和设定放到可浏览的空间中。** 使用背景图与对象标记展示世界地图，适合城市分布、区域设定或场景位置整理。

- 选择数据来源类，并绑定标记标题、说明、坐标与图片。
- 支持当前对象与固定对象来源，配置背景及图例。
- 平移、光标缩放、适应视图，选择和拖动标记。
- 双击标记打开对应源实例，继续完善资料。
- 标记拖动保存为该视图的独立布局，不自动改写源坐标。

地图使用背景图片上的坐标，适合自绘世界地图。它目前不提供经纬度 GIS 或在线地图服务。

## AI 创作助手

### 选择模型，围绕当前世界展开交流

MyUniverse 支持配置 OpenAI 兼容接口的 LLM 连接，包括服务地址、密钥和模型名称。可获取模型目录，也可手动填写模型标识；支持配置温度、采样、输出上限、超时等参数，并提供连接测试。

聊天可以选择直接调用模型，也可以选择自定义 Agent。答复流式显示，正文支持标题、列表、表格与代码块；服务提供的思考内容、工具过程和子 Agent 调用可展开查看。连续工具调用合并显示，便于阅读长过程。

会话按世界管理，支持新建、切换和删除。用户消息可以复制、编辑重发；生成时可停止等待，已显示的内容继续保留。编辑重发会重新生成后续对话，已采纳的世界修改保留。

### 让 AI 查询已有设定

给模型或 Agent 接入官方查询工具后，它可以按需了解类结构、实例与递归成员，围绕实际资料提出建议。这样，你能将创作要求与已有对象结合，例如请求整理人物动机、检查事件参与者或补充某个地点的描述。

接入哪些工具、哪些子 Agent，由你配置。模型是否使用某项能力以及生成质量，取决于所选服务与提示要求。

### 修改建议可检查、可采纳、可回退

官方建议工具支持新增实例、修改完整实例，以及定向修改某个子成员。聊天中展示修改前后的行差异，你可以展开查看后采纳或拒绝；相邻同类建议还可批量处理。

采纳时会再次检查结构和内容冲突。已采纳建议在满足回退条件时可回退，便于调整创作方向。采纳后更新工作区对象并自动存档到 JSON；需要 Markdown 文件时再明确导出。

AI 还可以通过“向用户提问”工具暂停当前调用，在聊天中提供选项或等待自填回答，再继续后续流程。例如，先确认叙事视角，再生成对应的设定建议。

## Agent 与可视化工作流

**把一次有效的创作方法，变成可重复运行的流程。** Agent 将输入、消息、模型、工具和子 Agent 放在同一张节点画布上，通过连线表达数据与执行依赖。

### 自由编排多步骤任务

基础 LLM 节点负责模型请求，ToolCalls 节点负责执行模型提出的工具调用；配合消息合并、条件和循环，可设计连续多轮的交流过程。条件只执行选中的分支，循环支持轮次上限，帮助控制复杂流程的执行范围。

例如，你可以自行编排“读取设定 → 生成草案 → 调用审校 Agent → 返回建议”的创作流程，并按项目调整模型、工具与提示内容。

### 变量、记忆与执行观察

变量池支持 String、Number、Boolean、Messages、Image、Tools、Agents 七种类型。变量可以拖入画布或兼容端口，用于保存消息上下文、图片或能力集合；初始值、本次运行值与成功提交的记忆分别管理。

运行时可查看节点状态、连线值、循环轮次及子调用过程。Agent 支持按世界或全局保存记忆，根运行成功后提交；失败或取消不提交暂存记忆。调用深度、节点执行数和能力调用预算可以配置，便于约束递归流程。

### 子 Agent 与自带示例

Agent 可作为另一 Agent 或模型的能力，按自己的参数结构被调用。内置入口可创建可编辑的工具调用模板，以及“创作 Agent + 审校 Agent”的 Multiagent 示例，帮助你从已有结构开始搭建。

画布支持节点库搜索、拖放创建、连线、多选、框选、复制粘贴、右键菜单、撤销重做、平移缩放，以及工作流 JSON 导入导出。配置、节点库与运行结果在右侧停靠区切换，编辑和观察都在同一空间完成。

## ComfyUI 绘图工作流

**将图片生成接入你的创作工具链。** 配置外部 ComfyUI 服务后，MyUniverse 可以读取该服务实际安装的节点目录，在可视化画布中组织绘图流程。

- **读取节点库**：展示服务的官方与自定义节点，以及对应输入、枚举和输出。
- **基础文生图模板**：生成起始图，由你选择可用 checkpoint 并调整参数。
- **导入与导出**：支持 MyUniverse 工作流 JSON，以及 ComfyUI API 格式 JSON。
- **数据前处理**：通过输入、常量、世界对象、运算和文本拼接等节点，将所需数据组织为原生节点参数。
- **执行与结果**：提交任务、查询状态，展示服务输出的图片；缺少节点、必填项或出图结果时提供错误反馈。

你可以据此搭建人物概念图、地点氛围图等流程。ComfyUI、模型文件与 GPU 运行环境由外部服务提供；停止等待后，已提交的远端任务可能继续运行。

## Function 与工具扩展

### Function：为设定添加程序生成内容

Function 可以绑定到对象属性，以 JavaScript、Python 或可视化 Flow 编写内容扩展逻辑。函数读取当前实例和绑定输入，通过类型化 `add` 接口向允许重复的成员及其子对象添加内容。

适合根据已有字段整理补充条目、生成规则化说明或展开重复子对象。生成成员标明函数来源，用户填写内容与程序维护内容各自清晰；生成成员只读，可通过显示开关临时隐藏。

刷新在填入 Markdown 后重新计算当前范围的绑定函数，也可通过“重新计算函数”单独执行；编辑、改名、切页和选择文件导入不会自动执行。生成结果逐实例提交并自动存档到 JSON，保存键负责导出。导出的 Markdown 只展示内容和实例名称，不混入函数标记或对象引用链接；导入按属性配置填入 JSON，保留未包含的实例和分支，相同值保留函数来源，新增或改动值作为用户内容。函数只能在已声明的绑定范围中添加符合结构的成员，不能修改既有用户值或自行扩展属性结构。

函数页提供源码或 Flow 编辑、对象调用助手、接口速查与绑定上下文测试。JavaScript 与 Flow 在独立后台线程执行，可终止超时或死循环任务；Python 需要桌面环境中的 Python 3。

### 自定义 Tool：连接你的接口与处理逻辑

Tool 面向模型与工作流，可定义调用名称、用途说明、参数 JSON Schema、启停状态及相关注释。

| 类型 | 主要用途 |
| --- | --- |
| JavaScript Tool | 读取世界对象、执行自定义处理逻辑，按门面接口修改草稿 |
| HTTP Tool | 配置 GET/POST、地址、密钥和请求体形式，调用外部业务接口 |

工具有独立配置与测试面板。参数经过 Schema 校验，返回字符串或可传输 JSON；脚本世界修改经过单次调用的草稿校验与冲突检查。官方工具与自定义工具使用统一注册入口，可在模型和工作流中选择接入。

Function 与用户 Tool 可在各自分类中创建虚拟文件夹、排序和组织，适合逐步积累自己的创作处理库。扩展开发者还可参考[世界对象 API](docs/features/api.md)。

## 主题与日常操作

### 随时查看运行日志

帮助按钮下方的终端图标可打开底部日志面板，覆盖显示，不打乱正在编辑的页面。程序状态、格式校验、函数与工具执行、脚本输出和错误都带有时间、级别和来源，方便找到问题发生的位置。

支持搜索、级别筛选和清空；点击空白处或再次点击图标即可收起。当前会话保留最近 2000 条，重复与高频输出合并，减少日志对操作流畅度的影响。详见[运行日志](docs/features/runtime-log.md)。

### 为长时间创作调整外观

提供“星雾蓝紫”“经典暗黑”“晨光浅色”三套预设，也可从当前配色创建自定义主题，命名并调整导航、侧栏、画布、输入框、正文、强调色与交互状态。

图关系、聊天、差异标记与 Markdown 高亮都有专用配色。颜色选择支持透明度与色板，可搭配个人工作习惯设置画布与阅读环境。

### 保留工作位置，减少重复操作

页面会话保留搜索、展开、滚动、视角和面板状态，切换后可继续原先位置。树导航、列表和画布提供拖动整理；常用动作可以通过按钮、右键或快捷键执行。

| 快捷键 | 使用范围与动作 |
| --- | --- |
| `Ctrl + S` | 明确导出当前文件；JSON 对象独立自动存档 |
| `Ctrl + R` | 明确导入对应 Markdown 并重算函数 |
| `Ctrl + C / X / V` | 实例列表或工作流画布的复制、剪切、粘贴 |
| `Delete` | 删除所选实例或工作流对象 |
| `Ctrl + Z / Y` | 实例列表或工作流编辑的撤销、重做 |
| `Tab` | 工作流画布展开或收起节点库 |
| `Esc` | 取消当前连接或退出相关聚焦、浮层状态 |

输入框获得焦点时，复制、粘贴等编辑快捷键继续用于文字操作。

## 开始创作

1. **打开桌面程序**：在当前项目交付目录中，使用 `my-universe.exe - 快捷方式.lnk`，或运行 `src-tauri/target/release/my-universe.exe`。
2. **创建世界**：为作品命名，从人物、势力、地点和事件等基础类别开始。
3. **完善对象**：先调整属性结构，再创建实例、填写资料并建立引用。
4. **探索视图**：打开人物关系网、关系类型网或地图，调整展示方式并保存配置。
5. **接入 AI**：在模型页填写兼容服务地址、密钥和模型，测试连接，再选择需要接入的工具或 Agent。
6. **检查并保存**：查看 Markdown 差异或 AI 建议，确认 JSON 存档状态，按需导出；定期备份程序同目录的 `user` 文件夹。

先用少量人物和地点建立一个小世界，再扩展模板、工作流和绘图服务，通常更容易形成自己的使用习惯。

## 常见问题

<details>
<summary><strong>必须使用 AI 才能创作吗？</strong></summary>

世界管理、对象编辑、Markdown、搜索筛选、关系网、地图和主题可以独立使用。需要 AI 答复时，再接入模型服务；调用费用与服务条件由所选供应商决定。

</details>

<details>
<summary><strong>我的设定保存在哪里？会发送给模型吗？</strong></summary>

桌面版资料与配置保存在程序同目录的 `user` 文件夹。模型调用会将构造的消息上下文、工具描述和后续工具结果发送到你配置的服务；HTTP 工具也会向配置地址发出请求。请按项目要求选择服务。API Key 当前保存在本地配置 JSON 中，未额外加密，备份或分享目录前需留意其中的密钥。

</details>

<details>
<summary><strong>AI 会直接覆盖我的设定吗？</strong></summary>

官方新增与修改建议先显示差异，等待你采纳，采纳后自动保存到 JSON。自定义 JavaScript Tool 可以按其实现修改世界草稿；请在接入模型前检查工具用途和代码。绑定 Function 只在规定范围添加生成成员，不修改既有用户值。

</details>

<details>
<summary><strong>能用其他编辑器修改 Markdown 吗？</strong></summary>

可以，但正文需符合已声明的类结构。外部修改后在应用中刷新读取；新增属性应先配置结构。应用启动只读 JSON；不会自动发现未注册文件，也不在导出时合并外部改动。备份建议包含整个 `user` 目录，以保留身份、结构和视图配置。

</details>

<details>
<summary><strong>绘图功能需要安装什么？</strong></summary>

需要可访问的 ComfyUI 服务及其模型和运行环境。MyUniverse 提供节点编辑、请求提交和结果展示。当前支持 ComfyUI API 格式 JSON，普通前端布局 JSON 与自动插图归档尚未提供。

</details>

<details>
<summary><strong>还有哪些接入条件需要了解？</strong></summary>

LLM 服务需要兼容当前消息与工具调用协议，具体参数支持取决于服务。Python Function 需要 Python 3。新绑定 Function 的 void/add 模式需要具体成员上下文，当前通用 Agent/SD Function 节点尚不能直接运行它来写入世界。工具目前通过应用内部注册接入模型；远程 MCP 服务器连接、Skill 自动注入与插件安装执行尚未提供。章节、插图是可组织内容的集合，尚无自动章节任务。

</details>
